# AK Trade Expansion

Minecraft Java Edition 26.3 向けの Fabric Mod です。コインと屋台で売り買いする、**相場が動く経済**を追加します。

売りすぎると値が下がり、買い占めると値が上がって売り切れます。時間がたつと相場は元に戻ります。近くの市場どうしは相場が連動し、遠くの市場とは値段に差が出るので、安い村で仕入れて高い村で売る「商いの旅」が遊べます。

## 特徴

- **5種類のコイン**と、財布・銀行・クレジットカード。支払いもお釣りも自動です
- **交易所（屋台）**を置いた場所が市場になります。新しく生成される村には、屋台と商人が建ちます
- 地域・次元・村の規模で変わる**品揃え**（145種類の商品）と、毎日入れ替わる「本日の掘り出し物」
- **掲示板**で近くの市場の相場を調べ、**依頼**や**輸送依頼**で稼げます
- **品不足・村の流行・商会の動き**で、自分が何もしなくても地域の相場が動きます
- 村ごとの**評判**、みんなで村に建物を建てる**村の発展**、留守の間も商売をする**雇い人**
- 村人・行商人から買う時の代金も**コイン**になります
- 専用の進捗タブ「**商いの始まり**」（29個）
- 値段や仕組みは、設定ファイル・ゲーム内の設定画面・データパックで調整できます

## 導入

1. Fabric Loader をインストールし、Minecraft 26.3 の Fabric の起動構成を作ります
2. Fabric API を `mods` フォルダに入れます
3. 配布 zip の中の `ak_trade_expansion-<バージョン>.jar` を `mods` フォルダに入れます（古い `ak_trade_expansion-*.jar` があれば先に消します）
4. （任意）Mod Menu と YACL、JourneyMap、JEI か REI を `mods` フォルダに入れます
5. Fabric の起動構成で起動します

- `mods` フォルダの場所（Windows の既定）：`%APPDATA%\.minecraft\mods`
- **導入前にワールドのバックアップを取ってください。** この Mod を外すと、コイン・財布・交易所などのアイテムとブロックはワールドから消えます。
- マルチプレイでは、サーバーとすべてのクライアントに同じバージョンを入れます。
- 新しいバージョンに入れ替えても、**すでにある市場の品揃えは変わりません**（新しく作られる市場から反映されます）。すでにある市場も更新したい時は「[既存のワールドの品揃えを更新する](#既存のワールドの品揃えを更新する)」を参照してください。

## はじめ方

1. **お金をもらう**：初めてワールドに入ると、所持金として 240c（パン10個分）がもらえます。
2. **市場を見つける**：新しく生成された村（平原・砂漠・サバンナ・雪原・タイガ）には、交易所の入った屋台と商人がいることがあります。見つからなければ**交易所**をクラフトして村に置きます。

   | 段 | 材料 |
   |---|---|
   | 1段目 | カーペット・カーペット・カーペット |
   | 2段目 | 木材・エメラルド・木材 |
   | 3段目 | 木材・樽・木材 |

   交易所を手に持つと、置いた時にどうなるか（市場に加わる／新しい市場ができる／置けない理由）が画面下に出ます。
3. **取引する**：交易所か商人を右クリックすると交易画面が開きます。「購入」「売却」タブで商品と数量を選んで確定します。
4. **財布を作る**：革×5と糸×2でクラフトします。拾ったコインやお釣りが自動で財布に入ります。
5. **慣れてきたら**：「掲示板」タブでほかの村の値段を調べて運んで売る、「依頼」をこなす、村の評判を上げる、村に建物を建てる、雇い人に商売を任せる、と遊びが広がります。

> クリエイティブモードでは取引できません（無限のアイテムで経済が壊れないようにするため）。サバイバルで遊んでください。試す時は設定 `trade.allowCreative` で許可できます。

## 遊び方

### お金

| コイン | 価値（既定） |
|---|---|
| 銅貨 | 1c |
| 鉄貨 | 10c |
| 金貨 | 100c |
| ダイヤ貨 | 1,000c |
| ネザライト貨 | 10,000c（溶岩で燃えない） |

- 値段はすべて銅貨単位（c）です。支払いは財布とインベントリのコインから自動で行い、お釣りは財布に（財布が無ければ最小の枚数のコインで）返ります。入りきらない分は足元に落ちます。
- **手に入れ方**：初回の 240c、市場で売る、依頼を納める、プレイヤーが倒した敵対モブのドロップ（銅貨0〜2枚、まれに鉄貨。ネザーではごくまれに金貨）、**鋳造**（作業台で銅ブロック×9 → 銅貨64枚。素材を売るよりずっと安い、余った素材の受け皿です。鉄ブロックの鋳造は、アイアンゴーレムトラップで無限に稼げてしまうため既定では無効）。
- **両替**：コインを持ってスニーク＋右クリックで、1枚を1段下のコインに崩せます。交易画面の「両替」タブでは、崩す・まとめるの両方ができます（手数料は既定で無し）。

| | 内容 |
|---|---|
| **財布** | コインを金額としてしまうアイテム（革×5＋糸×2、容量 20,000c）。拾ったコイン・お釣り・売却代金は自動で財布に入ります。コインを財布の上に重ねて（右クリック）入れることもできます。財布を右クリックすると取り出し画面が開きます。死ぬと財布ごと落とします |
| **銀行** | 市場レベル3（大きな村）以上の市場と、村に「銀行」を建てた市場の交易画面に「銀行」タブが出ます。預けたお金は死んでも失いません。預金には**利息**が付きます（ゲーム内1日 0.03%、10日で約 0.3%、毎日複利。利息が付くのは 100,000c まで） |
| **クレジットカード** | 銀行タブで発行します（手数料 100c、口座から）。持っていれば、どの市場でも「支払い：カード」で銀行残高から払えます（売却代金も口座へ）。持ち主専用で、再発行すると古いカードは使えなくなります |
| **エメラルド貨** | 石切台でエメラルドブロック1個から1枚作れる補助コイン（所持金には数えません）。**どの市場でも**10枚単位で売れます（10枚で4c。値段は変わらず、いくらでも売れます）。村人交易でたまるエメラルドを、少しずつお金に換えるための仕組みです |

### 市場と交易所

- 半径64ブロック以内の交易所は1つの「**市場**」になり、在庫と相場を共有します。
- 既存の市場から 64〜256 ブロックの場所には、新しい交易所を置けません（相場をリセットする抜け道を防ぐため）。
- 256 ブロック以上離れた場所に新しい市場を作るには、周り（半径64ブロック）に**村人が3人以上、ベッドが3個以上かつ村人の数以上**あることが必要です（既定）。ベッドが5個以上あれば、村人の方が多くても作れます。ネザー・エンドでは村人の数だけで判定します。条件は設定 `market.newMarketRequires` で「村の中だけ」「ベッドの数」「村人の数」にも変えられます。
- `/aktradeex where` で今いる場所の情報（村の範囲内か・近くの市場・ベッドと村人の数・置いた時の結果）が、`/aktradeex where show` で範囲が30秒間パーティクルで見られます（緑：村、黄：同じ市場になる範囲、赤：新しい市場を作れない範囲、青：ベッド・村人を数える範囲）。
- **商人**：交易所を開くと、交易所の前に商人が現れます（いなくなっていれば次に開いた時にまた現れます）。商人を右クリックしても同じ交易画面が開きます。商人は倒せず、その場から動きません。交易所を壊すと一緒に消えます。スポーンエッグや `/summon ak_trade_expansion:trader` で出した商人は、近く（64ブロック以内）の市場で取引できます（商人だけでは新しい市場は作れません）。
- **村の屋台**：設定 `worldgen.protectNaturalStalls` を ON にすると、村の交易所をサバイバルで壊せなくなります（既定 OFF）。
- **市場名**：金床で名前を付けた名札を持って交易所を右クリックすると、その市場に名前を付けられます（名札は1枚使います）。名前を付けた交易所を置いて新しい市場を作った時も、その名前になります。名前を変えられるのは名付けた人（自分で作った市場なら作った人）と管理者だけです。名前が無い市場は「平原の村 #12」のように表示されます（# の後ろが市場の ID）。

### 交易画面

| タブ | 内容 | 出る市場 |
|---|---|---|
| 購入・売却 | 商品と数量を選んで取引する | すべて |
| 銀行 | 預け入れ・引き出し・カードの発行 | レベル3以上、または「銀行」を建てた市場 |
| 掲示板 | 近くの市場の相場・商会のニュース | すべて |
| 依頼 | 依頼と輸送依頼 | すべて |
| 両替 | コインを崩す・まとめる | すべて |
| 発展 | 発展度・寄付・建物 | オーバーワールドの市場（設定で変更可） |
| 雇い人 | 運び屋・番頭を雇う・管理する | すべて（設定で OFF にすると出ない） |

- 交易画面のいちばん上の行に、市場名に続けて「│ 評判：常連」「│ 流行」が出ます。マウスを乗せると詳しい内容が見られます。
- 購入・売却の一覧は、値段（基準価格）の安い順に並びます。
- 一覧の ▲▼ は画面を開いてからの値動き、右端のメーターは基準価格からのずれ（右・赤＝高い、左・緑＝安い）です。行にマウスを乗せると直近14日の価格グラフが出ます。
- 色の意味：品不足の商品はオレンジ、**本日の掘り出し物**は★付きの水色、売り切れ・買取停止の商品は赤みがかった灰色（マウスを乗せると理由と「入荷まで約○分」「買取再開まで約○分」）。
- 左下の「**売却枠**」に品物を置くと、売却タブでその商品が選ばれます。置いた品も売却の対象になり、画面を閉じるとインベントリに戻ります（買取停止の品なら枠が赤くなります）。
- Shift を押しながら確定すると、できる最大の数量（最大36スタック）でまとめて取引します。
- **まとめ買い割引**：1回に16個以上買うと5%、64個以上で10%引きです（売却には付きません）。値段の安い商品やスプレッドの小さい商品では、売り戻して儲からないように割引が小さくなることがあります。
- **まとめて売る**（売却タブ）：この市場が買い取る物を一度に売ります。ホットバー（手元の9枠）の品と、道具・防具は売りません。確認の枠で行をクリックすると「除外」を切り替えられ、選んだ除外は次からも覚えています。
- 所持金（現金・銀行）はインベントリの右に出ます。表示位置は設定の「表示」タブ（`client.balancePosition`）で「売却枠の下」「右上」にも変えられます。
- 画面はウィンドウに余裕があると大きく開きます（商品一覧は最大10行）。マイクラの「GUIの大きさ」を小さくすると、より大きく表示されます。一覧のスクロールバーは、ドラッグ・溝のクリック・マウスホイールで動かせます。
- 設定 `trade.acceptDamaged` を ON にすると、耐久が減った道具・防具も残りの耐久の割合で安く買い取ってもらえます（既定 OFF）。

### 相場のしくみ

- 売るたびに値段が少しずつ下がり、買うたびに上がります。まとめて取引しても1個ずつ取引しても合計は同じです（購入はまとめ買い割引の分だけ、まとめて買う方が安くなります）。
- 同じ市場で売ってすぐ買い戻しても儲からないように、買値と売値には差があります。
- ずれた相場は、ゲーム内2日で半分元に戻ります。在庫も時間で補充されます。
- 売りすぎて在庫が上限に届くと「買取停止」になりますが、市場が在庫を少しずつ使うので、時間がたつとまた買い取ってもらえます。
- 食料・松明・燃料・原木・木材・丸石・砂・ガラス・花などの**消耗品**は早く使われます。上限まで売っても1日（現実の20分）で元の在庫に戻り、値段も1日で半分戻ります。消耗品は、設定画面の「商品」タブ →「追加の商品と消耗品」、管理コマンド `/aktradeex consumable`、設定 `consumables.add`・`consumables.remove`、アイテムタグ `#ak_trade_expansion:consumables` で増やしたり外したりできます。
- 取引の影響は近くの市場にも伝わります（128 ブロック以内は100%、1,536 ブロックで0%。在庫は伝わりません）。ネザーの市場は、座標を8倍してオーバーワールドの市場とも連動します。

### 品揃えと市場の規模

- 扱う商品は、市場を作った場所で変わります。
  - オーバーワールド：平原・砂漠・サバンナ・雪原・タイガの村、ジャングル、沼地、海辺（浜辺・海）、プレイヤーが作った市場
  - ネザー（金・ネザーの素材・幹）、エンド（エンダーパール・シュルカーの殻・エリトラなど）
- 商品は全部で145種と、補助コインのエメラルド貨です（下の「[商品一覧](#商品一覧)」）。1つの市場が扱うのは、そのうち10〜20種です（村に「屋根つき市場」を建てると +2）。
- 市場には**規模（レベル）**があり、高いほど商品が多く、高級品も並びます。

| レベル | 名前 | ベッド数 | 村人の数 | 商品数 |
|---|---|---|---|---|
| 1 | 集落 | 0〜4 | 0〜2 | 10 |
| 2 | 村 | 5〜9 | 3〜5 | 13 |
| 3 | 大きな村 | 10〜19 | 6〜11 | 15 |
| 4 | 町 | 20〜39 | 12〜23 | 18 |
| 5 | 都市 | 40〜 | 24〜 | 20 |

- 市場の中心から半径64ブロック以内の**ベッドの数と村人の数**を数え、低い方のレベルになります（例：ベッド8個＝レベル2、村人13人＝レベル4 → レベル2）。ネザー・エンドではベッドが使えないので、連れて来た村人の数だけで測ります。村に建物を建てると、さらに上がります（「[村の発展](#村の発展)」）。
- 画面を開いた時にレベルを測り直し（ゲーム内1日に1回まで）、上がっていれば商品が増えます。村人が家の中や畑に出ていて範囲の外にいると数えられないので、日によって上下することがあります。
- レベルが下がると、最後に並んだ商品から外れます。外れた商品の値段と在庫は覚えていて、レベルが戻ると同じ商品が戻ります。
- **本日の掘り出し物**：毎日、その市場がふだん扱わない商品が並びます（レベル1〜2で1品、3以上で2品）。値段は2割高く、在庫は少なめで、次の日には入れ替わります。
- 設定画面の「商品」タブ →「追加の商品と消耗品」で、アイコンからアイテムを選び、基準価格を入れて**商品を追加**できます。追加した商品は掘り出し物として並ぶことがあります。

### 掲示板・依頼・品不足

| | 内容 |
|---|---|
| **掲示板** | 半径512ブロック以内（同じ次元）の市場の一覧と、方角・距離。市場を選ぶと、その市場の全商品の買値・売値が見られます（タブを開いた時点の値段。離れた市場とは取引できません）。今いる市場より安く買える品（水色「安n」）・高く売れる品（桃色「高n」）の数も出て、マウスを乗せると一番お得な品とその差が出ます。「**地図に登録**」で、JourneyMap があれば市場を地図の地点に追加し、無ければ座標をチャットに出します（クリックでコピー）。一覧の右下の「**この市場を登録**」で、今いる市場も同じように登録できます |
| **依頼** | 市場が「この品を何個」と依頼を出します（1市場に最大3件、ゲーム内3日で期限切れ）。納めると基準価格の1.2〜2.0倍の報酬（★1〜3。高額な依頼ほど倍率が高い）。「依頼を受ける」を押しておくと、納めた時の評判が多く増えます（受けたまま期限が切れると評判が下がります）。★★★の依頼は評判「お得意様」以上で納品できます |
| **輸送依頼** | 「この品をほかの市場へ運んでほしい」という依頼です（1市場に1件、届け先は 300〜2,000 ブロック先）。「荷箱を受け取る」で保証金（品の値段）を払って荷箱をもらい、届け先の市場の依頼タブで「荷箱を届ける」を押すと、報酬と保証金を受け取れます。遠いほど報酬が多く（1,000 ブロックで品の値段と同じくらい、最大2倍）、依頼元と届け先の両方で評判が上がります。期限を過ぎると届けられず、保証金は戻りません |
| **品不足** | ゲーム内3日ごとに、市場ごとに最大2種類の商品が品不足になり、基準価格が1.5〜2.0倍になります（一覧や掲示板でオレンジ色）。品不足の品を売ると評判も多く上がります |

### 村の流行

村（市場）ごとに、何日か続く**流行**があります。「この村は今、食料が人気（高い）」「花が余り気味（安い）」のように、分野ごとに値段が変わります。

- ゲーム内5日ごとに選び直します（村ごとに変わる日がずれます）。人気の分野は基準価格が 1.15〜1.30 倍、余り気味の分野は 0.80〜0.90 倍になり、買値・売値の両方が変わります。
- 分野は「食料・植物と特産・木材・建材・鉱物・モブの素材・日用品・武器防具道具・ネザーの品・エンドの品・花」の11種で、その村が2品以上扱う分野から選ばれます（掘り出し物には付きません）。
- 交易画面の上の行の「│ 流行」、購入・売却の一覧の行、掲示板の市場の行にマウスを乗せると、流行が見られます。
- 遊び方の例：余り気味の村で安く仕入れ、人気の村で高く売る。

### 商会の動き

目に見えない**商会**（NPC の商人の集まり）が、何日かおきに近くの市場で品を**買い集め**（値上がり）たり**売りさばい**（値下がり）たりします。

- 1日に1回、半々の確率で新しい動きが始まります（同時に最大3件）。1件は2〜4日続き、最終日には中心の市場の値段が 15〜35% ずれます。中心から 128 ブロック以内は同じだけ、遠いほど少なく、640 ブロックより遠い市場には効きません。終わると、ふだんどおり時間で元に戻ります（在庫は減りません）。
- 掲示板の市場一覧の上に**ニュース**として出ます（例：「【鉄槌商会】鉄インゴットを買い集め中　北東 340m　あと2日」）。行をクリックすると、その市場の商品を開きます。購入・売却の一覧でも、動いている商品の行にマウスを乗せると出ます。

| 商会 | 扱う品 |
|---|---|
| 鉄槌商会 | 鉱物・建材・武器・防具・道具 |
| 豊穣商会 | 食料・植物と特産・花 |
| 大樹商会 | 木材・モブの素材・日用品 |
| 黄昏商会 | ネザーの品・エンドの品 |

- 遊び方の例：買い集めている地域へ品を運んで高く売る。売りさばいている地域で安く仕入れて、ほかの村で売る。

### 評判

村（市場）ごとに、あなたの**評判**があります。交易画面のタイトルの後ろの「│ 評判：○○」にマウスを乗せると、効果と次のレベルまでのポイントが見られます。

| レベル | 名前 | 必要なポイント |
|---|---|---|
| 0 | よそ者 | 0 |
| 1 | 顔見知り | 50 |
| 2 | 常連 | 150 |
| 3 | お得意様 | 400 |
| 4 | 信頼の厚い客 | 1,000 |
| 5 | 名士 | 2,500 |

- **上がる**：その市場で売り買いする（100c で1ポイント。品不足の商品を売ると2倍）、依頼を納める（★1＝10・★2＝25・★3＝50。受けた依頼なら1.5倍）、市場の近くの村人と取引する（1回1ポイント）、「発展」タブで寄付する（発展度1につき0.03）
- **下がる**：時間がたつ（ゲーム内30日で半分）、市場の近くの村人や商人を攻撃する（1回 −20、倒すと −100）、受けた依頼の期限が切れる（★1つにつき −10）
- **効果**：レベル1つごとに買値が1%安く・売値が1%高くなります（レベル5で5%。売り戻して儲からないよう、商品によっては小さくなります）。依頼の報酬がレベルごとに4%増えます。レベル2で建物を選べる・雇い人を雇える、レベル3で★★★の依頼を納められる、レベル4で「評判の掘り出し物」が1品見えるようになります。

### 村の発展

村（市場）ごとに、みんなで貯める**発展度**があります。発展度を使って村に**建物**を建てると、建物ごとの効果が付き、市場の規模も上がります。交易画面の「**発展**」タブで、発展度・建物・発展度を多く入れた人（マウスを乗せると上位5人）と自分の値が見られます。

- **貯まる**：依頼を納める（報酬の半分。輸送依頼は依頼元と届け先の両方）、その市場で売り買いする（100c で2）、コインを寄付する（1c で1。100c／1,000c／10,000c。カード払いなら口座から、手数料なし）、建物の**資材**を寄付する（基準価格の1.5倍。建物を選んで「資材を寄付」。建物ごとに必要な数まで）
- 「発展」タブの建物は、必要な発展度の少ない順に並びます。
- 発展度は時間では減りません。使えるのはオーバーワールドの市場です（設定 `development.dimensions` でほかの次元も足せます）。

- **市場の規模**：完成した建物が2つで +1、4つで +2（家と村人で決まる規模に足します。最大は「都市」）。
- **壊れた時**：建物の中の**看板**を壊すと、その建物の効果がなくなります（ほかのブロックを壊しても効果は消えません）。「発展」タブで、半分の発展度で建て直せます（別の場所に建ちます）。設定 `development.protectFacilities` を ON にすると、サバイバルでは壊せず、爆発でも壊れません。
- 完成した建物の看板を右クリックすると、その建物のタブ（依頼所＝依頼、銀行＝銀行、ほか＝発展）で交易画面が開きます。
- 建物の見た目は村の種類（平原・砂漠・サバンナ・雪原・タイガ）ごとに変わります（ジャングル・沼地などは平原の見た目）。ネザー・エンドを対象に足した時は専用の見た目になり、宿屋にはベッドを置きません（ベッドが爆発するため。効果は村人が来ることだけ）。

### 雇い人

交易画面の「**雇い人**」タブで、村人を雇って留守の間も商売をさせられます。雇えるのは、その村での評判が「**常連**」以上の時です（1人で3人まで）。

| 雇い人 | すること | 契約金 | 給金 |
|---|---|---|---|
| 運び屋 | 雇った村で品を仕入れ、ほかの村へ運んで売り、帰りはそこで仕入れた品を持ち帰って売る。これを繰り返す | 300c | 往復の利益の2割（利益が無い往復は払わない） |
| 番頭 | 預けた品を、決めた値段以上の時だけ、雇った村で少しずつ売る | 300c | 品を預かっている日ごとに 30c |

- 雇い人はそれぞれ**所持金**を持ちます。雇った村のタブで所持金を入れる（+100c・+1,000c、Shift で10倍）・引き出すができます。仕入れと給金は所持金から払い、売上は所持金に入ります。給金が足りないと休みます。
- **運び屋の雇い方**：一覧の先頭の「**おまかせ**」か、運ぶ品（この村で買える品）を選ぶ → 売りに行く村を選ぶ（2,000 ブロック以内）→ 設定して「雇う」。
  - 品と行き先の一覧には、今の値段のままなら1往復でどれくらい儲かるか（見込み）が出て、儲かる順に並びます。マウスを乗せると、おすすめの行き先・数・値段が見られます。
  - **おまかせ**：往復ごとに、行き先で高く売れる品を何種類も自動で選んで運びます。**ふつうはこちらの方が儲かります**。
  - **品を決める**：1種類だけ運びます。買値の上限（これより高い時は仕入れない）と売値の下限（これより安い時は売らない）を決められます。
  - どちらでも、行き先で仕入れ値より高く売れる分だけ仕入れ、仕入れ値より高い時だけ売ります。売れ残った分は1日待ってから持ち帰り、次の往復で先に売ります。運び屋は商人どうしの値段（**問屋値**：買値と売値の差が半分）で取引し、相場もあまり動かしません。
  - **帰り荷**：帰りも空では戻りません。行き先で、雇った村で高く売れる品を何種類も自動で選んで仕入れ（おまかせと同じ選び方）、戻った時に仕入れ値より高い時だけ売ります。売れ残った帰り荷は次に戻った時に売り、それまで帰り荷は買い足しません。行きに運ぶ品が無くても、帰り荷で儲かる見込みがあれば出かけます。行き先の一覧の見込みには帰り荷の分も入り、マウスを乗せると帰り荷の見込みが見られます。設定 `staff.carrierBackhaul` で止められます。
  - 片道の時間は距離で決まります（1,000 ブロックで約10分）。荷を運ぶ片道ごとに 1% の確率で**事故**に遭い、荷（帰り荷も）の1〜3割を失って少し休みます。
  - 儲けの目安（ゲーム内1日あたり、給金と事故の分を引いた額）：おまかせで平均 60〜70c、品を決めると平均 15c ほど（帰り荷の分は含みません）。品不足や流行で村どうしの値段の差が開いた時にまとめて儲かります。
- **番頭の雇い方**：売る品（この村が買い取る品）を選ぶ → 預ける数と**売値の下限**を決めて「雇う」。下限の初期値は今の売値の85%です。売るたびに値は下がり、時間で戻るので、市場が一度に受け付けない量も留守の間に少しずつさばけます。売り切ると止まります（「預ける」で品を足せます）。
- 雇った後でも、雇った村の「**変更**」で扱う品と行き先を選び直せます（契約金はかかりません。持っている品は手元に戻ります。運び屋は雇った村に戻っている時だけ）。
- 一覧にはどの村で雇った人も出ます。行にマウスを乗せると、様子・これまでの売上と費用・最近のできごとが見られます。お金・品・設定を変えられるのは雇った村だけです（「休止」はどこでもできます）。事故・辞めた・給金不足・売り切れはチャットでも知らせます。
- 雇い人の売買も相場を動かします。評判と村の発展度は上がりません。雇い人が働くのは、サーバー（1人で遊ぶ時はワールド）が動いている間です。

### 村人・行商人との取引

- 村人から品物を**買う**時の代金は、エメラルドではなく**コイン**になります（エメラルド1個＝30c で換算し、財布・コインから自動で払います）。取引一覧のエメラルドの上にコインでの代金が、支払い欄の下に「代金 ◯c（所持 ◯c）」が出ます。支払い欄にエメラルドを置く必要はありません。
- 村人が市場の商品と同じ品を売る時は、代金が市場の買値や「基準価格の1.4倍」より安くなりません（村人から安く買って市場で売る抜け道を防ぐため）。
- 村人に品物を**売る**取引は、今までどおりエメラルドがもらえます（エメラルドはエメラルド貨にして市場で売れます）。
- **値引き**（村人ゾンビの治療・村の英雄・村人の評判）は、コインの代金にも同じ割合で効きます（例：エメラルド10個 → 4個に値引きされた取引は 300c → 120c）。ただし、もともとエメラルド1個の取引はそれ以上安くならず、市場の商品と同じ品は上の下限が優先されます。
- 行商人から買う時もコインです。探検家の地図など、エメラルドと別の品が要る取引は、エメラルドの分だけコインで払い、別の品は支払い欄に置きます。

### 進捗

進捗の画面（L キー）に、この Mod のタブ「**商いの始まり**」があります（全部で29個。達成すると経験値がもらえます）。

- **商い**：交易所を置く、初めて売り買いする、1回で 1,000c 以上の取引、64個以上のまとめ買い、品不足の商品を売る、商会が買い集めている商品を売る、売りすぎて買取停止にする（隠し進捗）
- **旅**：3つ・10の市場で取引する、ネザー・エンドの市場で取引する
- **依頼**：依頼を納める、★3の依頼を納める、輸送依頼を届ける
- **評判と雇い人**：評判「顔見知り」「お得意様」「名士」、運び屋か番頭を雇う、運び屋の往復で利益を出す
- **村の発展**：寄付する、発展度を入れた村に建物が完成する、1つの村に8種類以上の建物がそろう
- **お金**：財布を手に入れる、銀行に預ける、カードを発行する、現金と銀行の合計で 10,000c・100,000c、ネザライト貨を手に入れる

評判・所持金・建物の進捗は、ログインした時と交易画面を開いた時にも判定するので、この機能が入る前に達成していた分も付きます（取引した市場の数は、この機能が入ってから数えます）。

### 他の Mod との連携

どれも任意です。入っていなくても、この Mod は普通に動きます。

- **Mod Menu＋YACL**：Mod 一覧の AK Trade Expansion の「設定」ボタンから、ゲーム内の画面で設定を変えられます（「[設定](#設定)」）。
- **JourneyMap**：掲示板の「地図に登録」「この市場を登録」で、市場を JourneyMap の地点として追加できます。
- **JEI・REI**（どちらか）：市場で扱う品で R（レシピ）か U（使い道）を押すと「**市場の相場**」のページが出ます。今いる場所から半径512ブロック以内（同じ次元）でその品を扱う市場を、近い順に5つまで、方角と距離・買値・売値・在庫と一緒に並べます（値段は自分の評判の割引込み。開いている間は数秒ごとに更新）。品不足の市場は名前がオレンジです。EMI には対応していません。

## 商品一覧

同梱の商品は145種と、補助コインのエメラルド貨です。1つの市場が扱うのはこのうち10〜20種（村に屋根つき市場があると +2）で、どれが並ぶかは市場の種類（地域・次元）と規模（レベル）で抽選されます。肉と魚は生のものだけを扱います（焼いた物は扱いません）。ほかに毎日1〜2品、その市場がふだん扱わない商品が「本日の掘り出し物」として並びます。

- **買値／売値** は平常時（相場のずれが0）の目安です。実際の価格は市場ごとのばらつき（±15%）、地域の価格倍率、品不足、村の流行、商会の動き、売買による相場の動きで変わります。
- **在庫** は平常時の在庫（目標在庫）です。上限はその2倍（ダイヤの剣・エメラルド貨は個別に設定）。
- **消耗品** は在庫と相場が早く戻る商品です（「相場の動き方」を参照）。
- **並ぶ市場** の「オーバーワールドの全市場」は、どの地域の市場でも抽選の候補になる日用品・高級品です。「（レベルN〜）」はその規模以上の市場だけで並ぶことを表します。地元の特産として、ほかより低いレベルから並ぶ地域は個別に書いています。
- 値は設定の `goods` や `/aktradeex goods set` で変えられます。ここに載っているのは既定値です。

## コマンド

`/aktradeex`（別名 `/ak_trade_expansion`）。

### だれでも使えるコマンド

| コマンド | 内容 |
|---|---|
| `/aktradeex balance` | 所持金を表示 |
| `/aktradeex bank balance` | 自分の銀行残高を表示 |
| `/aktradeex where` | 今いる場所の情報（村の範囲内か・一番近い市場・ベッドと村人の数・ここに市場を作った場合の規模・交易所を置いた時の結果） |

### 既存のワールドの品揃えを更新する

Mod を新しいバージョンに入れ替えた時や、データパックで商品を変えた時、**すでにある市場の品揃えは自動では変わりません**（新しく作られる市場から反映されます）。すでにある市場にも反映したい時は、品揃えを選び直します。

1. OP 権限を用意します
2. 選び直したい市場の交易所の近くで `/aktradeex market reroll` を実行します（離れた市場は `/aktradeex market reroll <ID>`）
3. 「市場 #12 の品揃えを選び直しました（…、15 商品）」と出れば完了です。交易画面を開き直すと新しい品揃えになっています

- **市場の ID**：交易画面のタイトルや `/aktradeex where` に出る「平原の村 #12」の、# の後ろの数字です。ID は 1 から順に付いているので、全部の市場を直す時は `reroll 1`、`reroll 2`… と順に実行します。
- **変わるもの**：扱う商品の組み合わせ、各商品の相場と在庫（初期値に戻る）、品不足・依頼・村の流行（選び直す）、市場のレベル（今のベッドと村人の数で測り直す。設定 `market.shrinkOnLevelDown` が OFF の時は下がらない）
- **残るもの**：市場の名前、交易所と商人、銀行の残高、村の発展度と建物、プレイヤーの持ち物
- 品揃えは場所ごとに決まった乱数で選ぶので、Mod やデータパックの内容が変わっていなければ、選び直しても同じ品揃えになります。

## 設定

設定は `config/ak_trade_expansion.json` にあります（初めて起動した時に、全項目が既定値で書き出されます）。

- **ゲーム内で変える**：Mod Menu と YACL を入れていれば、Mod 一覧の AK Trade Expansion の「設定」ボタンから画面で変えられます。シングルプレイでは保存した時点で反映されます。
- **マルチプレイ**：サーバーの設定ファイルを編集して `/aktradeex reload` を実行します。サーバーに接続中の設定画面では、サーバーの項目は灰色で表示され、変えられるのは自分の「表示」（`client.*`）の項目だけです。
- 範囲外の値は自動で範囲内に直されます（サーバーのログに警告が出ます）。書かれていない項目は既定値になります。
- 価格や相場の項目は、変えるとすでにある市場の値段もすぐ変わります。

### 設定ファイルの書き方

JSON の中は、下の表の「キー」の `.` の前がカテゴリ、後ろが項目名です。変えたい項目だけ書けば、残りは既定値になります。

```json
{
  "currency": { "exchangeFee": 0.02 },
  "price": { "globalMultiplier": 1.5 },
  "recovery": { "halfLifeDays": 1.0 },
  "trade": { "allowCreative": true, "maxPerTransaction": 128 },
  "worldgen": { "protectNaturalStalls": true },
  "client": { "balancePosition": "INVENTORY_RIGHT" }
}
```

### 設定値一覧

## データパックでのカスタマイズ

商品・品揃え・村の建物・商会はデータパックで変えたり足したりできます。`/reload` で読み直され、すでにある市場の値段にも反映されます（商品の構成は変わりません。変えたい時は `market reroll`）。

値段や在庫だけを変えたい時は、データパックを作らなくても、設定ファイルの `goods` か `/aktradeex goods set` で商品ごとに上書きできます。

| 種類 | 置き場所 |
|---|---|
| 商品定義 | `data/<namespace>/ak_trade_expansion/goods/<名前>.json` |
| 市場プロファイル | `data/<namespace>/ak_trade_expansion/market_profile/<名前>.json` |
| 村の建物 | `data/<namespace>/ak_trade_expansion/facility/<名前>.json`（建物の形は `data/<namespace>/structure/facility/<見た目>/<structure>.nbt`） |
| 商品グループ | `data/<namespace>/ak_trade_expansion/goods_group/<名前>.json`（`{"goods": [商品ID, …]}`。表示名は言語ファイルの `goods_group.<namespace>.<名前>`） |
| 商会 | `data/<namespace>/ak_trade_expansion/rival_guild/<名前>.json`（`{"groups": [商品グループID, …], "weight": 1}`。表示名は `rival_guild.<namespace>.<名前>`） |
| 消耗品 | アイテムタグ `#ak_trade_expansion:consumables` |

**商品定義**の例：

```json
{
  "item": "minecraft:diamond_sword",
  "base_price": 900,
  "elasticity": 16,
  "target_stock": 8,
  "max_stock": 24,
  "restock_per_day": 4,
  "buy": true,
  "sell": true
}
```

主な項目：`base_price`（基準価格）、`elasticity`（大きいほど値崩れしにくい）、`target_stock`（目標在庫）、`max_stock`（在庫上限。これ以上は買い取らない）、`restock_per_day`（補充速度）、`unit`（取引単位）、`buy`・`sell`（取引の向き）、`auto_add`（条件に合う市場に自動で追加）、`link`（近くの市場への相場の伝わりやすさ、既定 1.0）、`consume_per_day`（在庫が目標より多い時に1日に減る数）、`half_life_days`（相場の半減期）、`components`（エンチャントなど付加情報付きの品。例：`{"minecraft:enchantments": {"minecraft:sharpness": 1}}`）。

**市場プロファイル**では、条件（`dimension` / `biome` / `structure` / `villager_type` / `origin` / `distance_from_spawn` / `all_of` / `any_of` / `not`）、抽選プール（重み・`min_level`）、必ず扱う商品（`always`）、価格倍率（`price_modifiers`）を指定します。書式の詳細は設計書 D-2 を参照してください。

**村の建物**では、種類（`kind`：`quest_hall`・`warehouse`・`inn`・`bank`・`fountain`・`park`・`clock_tower`・`watchtower`・`tavern`・`market_hall`・`harbor`・`theater`・`hot_spring`・`festival`。種類ごとに1つ）、並び順（`order`）、タブのアイコン（`icon`）、必要な発展度（`cost`）、建物の形の名前（`structure`）、ほしい資材（`wanted`：`item` か `tag`、`count`、商品でない品の値段 `value`）、水辺に建てる時の陸の列数（`waterside`）を指定します。建物の形は北向き（`z = 0` の面が正面、扉は幅の真ん中）で、中に「施設の看板」を1つ置きます。見た目は村の種類（`plains` など）ごとのフォルダから選び、無ければ `plains` を使います。

**商品グループ**は、商会が扱う品と村の流行の分野に使う分類です（同梱は11種）。1つの商品がいくつかのグループに入ってもかまいません。**商会**は扱うグループの中から動かす商品を選びます（`weight` は選ばれやすさ、0 で使わない）。

同梱のデータは `Source/TradeExpansion/src/main/resources/data/ak_trade_expansion/` にあります。

## 開発

ソースコード（Gradle プロジェクト）は [Source/TradeExpansion](Source/TradeExpansion) にあります。必要なものは JDK 25 以上と、Fabric の Loom を使う Gradle プロジェクトが開ける IDE（IntelliJ IDEA など）です。仕様は[設計書](docs/trade-mod-design.md)と[商品・品揃え設計書](docs/goods-design.md)にまとめています。

`Source/TradeExpansion` で実行します：

| コマンド | 内容 |
|---|---|
| `build.bat` | 普段のビルド。バージョンの末尾を上げて（0.1.2 → 0.1.3。この README の表記も）、テストと jar（`build/libs/ak_trade_expansion-<version>.jar`）を作る。`build.bat nobump` で上げずにビルド |
| `release.bat` | 配布用のビルド。バージョンの真ん中を上げて（0.1.3 → 0.2.0）、jar と配布用 zip（`build/distributions/AKTradeExpansion-<version>.zip`：jar・導入方法の README.txt・LICENSE）を作る |
| `./gradlew test` | 単体テストだけを実行する（ゲームは起動しない） |
| `./gradlew runClient` / `runServer` | 開発用のクライアント／サーバーを起動する（Mod Menu と YACL も読み込まれる） |

- `runServer` を初めて動かす時は、`run/eula.txt` を `eula=true` にします（[Minecraft EULA](https://aka.ms/MinecraftEULA) に同意したことになります）。開発用クライアントから接続するには、`run/server.properties` で `online-mode=false` にします。
- OneDrive の同期フォルダで `Failed to clean up stale outputs` が出たら、`build` フォルダを消して実行し直します。
- 生成物：この README の「商品一覧」は、リポジトリ直下で `node Source/TradeExpansion/tools/docs/goodslist.js .` を実行して作ります。村の屋台と建物の構造物（`tools/structures/`）、進捗（`tools/advancements/genadv.js`）、アイコン（`tools/icon/`）もスクリプトで作ります。

| 場所（`Source/TradeExpansion/` から） | 内容 |
|---|---|
| `src/main/java/.../core/` | Minecraft に依存しない計算（価格・距離・コイン・市場レベル・商品の抽選・評判・利息・依頼・発展度・商会・流行・雇い人）。単体テストの大半はここが対象 |
| `src/main/java/...` のほかのパッケージ | 市場と保存データ（`market`）、取引（`trade`）、お金（`currency`・`bank`）、依頼と掲示板（`quest`・`board`）、商会（`rival`）、村の発展（`development`）、雇い人（`staff`）、進捗（`advancement`）、村人交易（`villager`）、村の屋台（`worldgen`）、商人（`entity`）、通信（`network`）、設定（`config`）、コマンド（`command`）、データパックの読み込み（`data`） |
| `src/client/java/...` | 交易画面などクライアント専用のコードと、他の Mod との連携（`compat/`） |
| `src/main/resources/data/ak_trade_expansion/` | 同梱のデータパック（商品・プロファイル・建物・商品グループ・商会・構造物・進捗・レシピ） |
| `src/test/java/...` | 単体テスト |
| `src/dist/README.txt` | 配布用 zip に入れる導入方法 |
