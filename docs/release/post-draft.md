## AK Trade Expansion とは

村に**市場**ができ、コインで売り買いする経済を追加する MOD です。

市場の値段は動きます。たくさん売れば値が下がり、買い占めれば値が上がって売り切れます。時間がたつと元に戻ります。
近くの村どうしは相場が連動し、遠くの村とは値段に差が出るので、**安い村で仕入れて、高い村へ運んで売る**――そんな商人の旅が遊べます。

稼いだお金で、村に建物を建てたり、人を雇って商売を任せたりもできます。ソロでもマルチでも遊べます。

【スクリーンショット：交易画面（商品一覧・値動きのメーター・価格グラフ）】

## できること

### コインで売り買いする
- 銅貨・鉄貨・金貨・ダイヤ貨・ネザライト貨の5種類（1c〜10,000c）。支払いもお釣りも自動です
- **財布**にまとめて持ち歩き、**銀行**に預ければ死んでも失いません（利息も少し付きます）。**クレジットカード**なら、どの市場でも銀行のお金で払えます
- 最初に 240c（パン10個分）がもらえます。ほかに、市場で売る・依頼を納める・敵モブを倒す・銅ブロックから鋳造する、で稼げます

### 村の屋台と、動く相場
- 新しく生まれる村には、交易所の屋台と**商人**が建ちます。交易所をクラフトして、自分で市場を作ることもできます
- 食料・木材・鉱物・花・海の品・鉄とダイヤの装備など**144種類の商品**。平原・砂漠・雪原・海辺などの地域や、ネザー・エンドで品揃えが変わります
- 村が大きくなる（ベッドと村人が増える）と、商品が増えて高級品も並びます。毎日1〜2品の「**本日の掘り出し物**」も
- 「**まとめて売る**」でインベントリの売れる物を一度に売れます。16個以上・64個以上のまとめ買いは割引されます

【スクリーンショット：村の屋台の建物と商人】

### 相場を読んで稼ぐ
- **掲示板**で、近くの村の今の値段と「お買い得な品」が分かります
- 村ごとに**品不足**（高く売れる）や**流行**（人気の分野は高く、余り気味の分野は安い）が数日ずつ入れ替わります
- 目に見えない**商会**が、ときどき地域の品を買い集めたり売りさばいたりして、相場を動かします。掲示板にニュースが出ます
- **依頼**（「この品を何個」）や、荷箱をほかの村へ届ける**輸送依頼**で報酬がもらえます

【スクリーンショット：掲示板タブ（市場の一覧とニュース）】

### 村と仲良くなり、村を育てる
- 村ごとに**評判**があり、取引や依頼で上がると、値段が少し有利になり、依頼の報酬が増え、難しい依頼や特別な品が解放されます
- みんなで**発展度**を貯めて、村に**建物**を建てられます。依頼所・倉庫・宿屋・銀行・噴水広場・公園・時計塔・見張り塔・酒場・屋根つき市場・港・野外劇場・温泉・祭りの広場の**14種類**。建物ごとに効果があり、村の規模も上がります。見た目は村の種類ごとに変わります

【スクリーンショット：村の発展の建物（噴水広場・時計塔など）】

### 人を雇って、留守の間も商売
- **運び屋**は、品を仕入れてほかの村へ運んで売り、戻ってくるのを繰り返します（「おまかせ」で儲かる品を自動で選びます）
- **番頭**は、預けた品を決めた値段以上の時だけ、少しずつ売ってくれます

### そのほか
- 村人・行商人から買う時の代金も**コイン**になります。村人からもらうエメラルドは「エメラルド貨」にして、どの市場でもコインに換えられます
- 専用の**進捗**タブ「商いの始まり」（29個）
- **JourneyMap** を入れると、掲示板から市場を地図に登録できます。**JEI・REI** を入れると、アイテムのレシピの画面で近くの市場の相場が見られます

## 導入方法

1. Fabric Loader をインストールし、Minecraft 26.3 の Fabric の起動構成を作ります
2. Fabric API を `mods` フォルダに入れます
3. ダウンロードした zip を展開し、中の `ak_trade_expansion-【バージョン】.jar` を `mods` フォルダに入れます（古いバージョンの jar があれば先に消してください）
4. （任意）Mod Menu と YACL、JourneyMap、JEI か REI を `mods` フォルダに入れます
5. Fabric の起動構成で Minecraft を起動します

`mods` フォルダの場所（Windows の既定）：`%APPDATA%\.minecraft\mods`

**導入前に、必ずワールドのバックアップを取ってください。**

## 遊び方

1. 村の屋台を探すか、**交易所**をクラフトして村に置きます
   - 1段目：カーペット ×3
   - 2段目：木材・エメラルド・木材
   - 3段目：木材・樽・木材
2. 交易所か商人を右クリックすると交易画面が開きます。「購入」「売却」タブで商品と数量を選んで取引します
3. **財布**（革 ×5 と糸 ×2）を作ると、コインが自動でまとまります
4. 慣れてきたら「掲示板」でほかの村の値段を調べて、運んで売ってみてください

- 交易所を手に持つと、置いた時に「市場に加わる／新しい市場ができる／置けない理由」が画面下に出ます。新しい市場を作るには、周りに村人とベッドが必要です
- **クリエイティブモードでは取引できません**（無限のアイテムで経済が壊れないようにするため）。サバイバルで遊んでください。設定で許可することもできます

## コマンド（だれでも使えるもの）

| コマンド | 内容 |
|---|---|
| `/aktradeex balance` | 所持金を表示 |
| `/aktradeex bank balance` | 銀行残高を表示 |
| `/aktradeex where` | 今いる場所に交易所を置くとどうなるかを表示 |
| `/aktradeex where show` | 村の範囲や市場の範囲を30秒間パーティクルで表示（`where hide` で消す） |
| `/aktradeex reputation` | 最寄りの市場での自分の評判を表示 |
| `/aktradeex development` | 最寄りの市場の発展度と建物を表示 |

サーバー管理者向けのコマンド（相場の初期化、品揃えの選び直し、商品の値段の変更、市場名の変更など）もあります。一覧は【ソースコードのURL】の README を参照してください。

## 設定

- 設定ファイル：`.minecraft\config\ak_trade_expansion.json`（サーバーではサーバーの `config` フォルダ。マルチプレイでは編集後に `/aktradeex reload`）
- Mod Menu と YACL を入れていれば、MOD 一覧の「設定」ボタンから画面で変えられます
- 変えられる主な項目：コインの比率、値段の動き方と戻る速さ、市場どうしの距離、まとめ買い割引、依頼・品不足・流行・商会の強さ、評判、村の建物の効果、雇い人の給金、預金の利息、村人の代金の換算、商品ごとの値段・商品の追加、など

## 注意事項

- 開発中のバージョンです。不具合があるかもしれません
- この MOD を外すと、コイン・財布・交易所などのアイテムとブロックはワールドから消えます
- 新しいバージョンに入れ替えても、すでにある市場の品揃えは変わりません（新しくできる市場から反映されます。管理者コマンド `/aktradeex market reroll` で選び直せます）
- 村人の取引内容や取引画面を変える MOD とは、相性が悪いことがあります
