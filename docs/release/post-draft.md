## AK Trade Expansion とは

コインと屋台で取引する、**相場が動く経済**を追加する MOD です。

たくさん売ると値が下がり、たくさん買うと値が上がって売り切れます。時間がたつと相場は元に戻ります。
近くの市場ほど相場が連動し、遠くの市場とは価格差が生まれるので、「安い地域で買って、高い地域で売る」交易の旅が楽しめます。

【スクリーンショット：交易画面（商品一覧・相場メーター・価格グラフ）】

## 主な特徴

### コインと財布・銀行
- 銅貨・鉄貨・金貨・ダイヤ貨・ネザライト貨の5種類（1・10・100・1,000・10,000c）。支払いもお釣りも自動です
- **財布**にコインをまとめて持ち歩けます（拾ったコインは自動で財布へ）
- 大きな村には**銀行**があり、預けたお金は死んでも失いません。**クレジットカード**でどの市場でも銀行のお金で払えます
- コインは、市場で売る・依頼を納める・敵モブを倒す・銅ブロックから鋳造する、で手に入ります（鉄ブロックの鋳造は、アイアンゴーレムトラップ対策で既定では無効）

### 屋台（交易所）と商人
- 交易所をクラフトして置くと、そこが市場になります。近く（64ブロック以内）の交易所は同じ市場になります
- 新しく生成される村には、屋台の建物と**商人**が現れることがあります
- 交易所を開くと、交易所の前に商人が出てきます。商人からも取引できます
- 名札で**市場に名前**を付けられます

【スクリーンショット：村の屋台の建物と商人】

### 地域ごとの品揃えと相場
- 食料・木材・鉱物・花・ダイヤの装備など**95種類の商品**。地域（平原・砂漠・雪原など）や次元（ネザー・エンド）で並ぶ商品が変わります
- 村が大きくなる（ベッドと村人が増える）と、市場の規模が上がって商品が増え、高級品も並びます。小さくなると商品が減ります
- 毎日1〜2品、その市場がふだん扱わない「本日の掘り出し物」が並びます
- 16個以上・64個以上のまとめ買いで割引されます
- 食料や松明などの**消耗品**は、市場で使われて早く元に戻ります
- 市場によっては**品不足**の商品があり、高く買い取ってもらえます

### 掲示板・依頼・両替
- **掲示板**で、近くの市場の今の価格を調べられます
- 市場の**依頼**（「この品を何個」）を納めると報酬がもらえます
- **両替**タブでコインを崩したり、まとめたりできます

【スクリーンショット：掲示板タブ】

### 村人との取引もコインに
- 村人・行商人から買う時の代金が、エメラルドではなく**コイン**になります（財布・コインから自動で払います）
- 村人に品物を売る取引は、今までどおりエメラルドがもらえます。エメラルドは「エメラルド貨」にして、村の市場で少しずつコインに換えられます

【スクリーンショット：村人の取引画面（コインの代金表示）】

## 動作環境

| 項目 | 内容 |
|---|---|
| Minecraft | Java Edition 26.3 |
| 前提 | Fabric Loader 0.20.1 以上、**Fabric API**（必須） |
| 任意 | Mod Menu、YetAnotherConfigLib（YACL）… 入れるとゲーム内の設定画面が使えます |
| Java | 25 以上（Minecraft のランチャーに含まれています） |
| マルチプレイ | 対応。サーバーとクライアントの両方に入れてください |

## 導入方法

1. Fabric Loader をインストールし、Minecraft 26.3 の Fabric の起動構成を作ります
2. Fabric API を `mods` フォルダに入れます
3. ダウンロードした zip を展開し、中の `ak_trade_expansion-【バージョン】.jar` を `mods` フォルダに入れます
4. （任意）Mod Menu と YACL を `mods` フォルダに入れます
5. Fabric の起動構成で Minecraft を起動します

`mods` フォルダの場所（Windows の既定）：`%APPDATA%\.minecraft\mods`

**導入前に、必ずワールドのバックアップを取ってください。**

## 遊び方

1. **交易所**をクラフトします
   - 1段目：カーペット ×3
   - 2段目：木材・エメラルド・木材
   - 3段目：木材・樽・木材
2. 置いて右クリックすると交易画面が開きます。「購入」「売却」タブで商品と数量を選んで取引します
3. 交易所を手に持つと、置いた時に「市場に加わる／新しい市場ができる／置けない」が画面下に表示されます
   - 新しい市場を作るには、周りに村人とベッドが必要です（既定の設定）
4. **財布**は、革 ×5 と糸 ×2 でクラフトできます

- クリエイティブモードでは取引できません（無限のアイテムで経済が壊れないようにするため）。サバイバルで遊んでください。設定で許可することもできます
- 交易画面の「売却枠」に品物を置くと、その商品がすぐ選ばれます。Shift を押しながら確定すると、できるだけまとめて取引します

## コマンド（誰でも使えるもの）

| コマンド | 内容 |
|---|---|
| `/tradeex balance` | 所持金を表示 |
| `/tradeex bank balance` | 銀行残高を表示 |
| `/tradeex where` | 今いる場所に交易所を置くとどうなるかを表示 |
| `/tradeex where show` | 村の範囲や市場の範囲を30秒間パーティクルで表示 |

サーバー管理者向けのコマンド（相場の初期化、商品の値段の変更、市場名の変更など）もあります。一覧は【ソースコードのURL】の README を参照してください。

## 設定

- 設定ファイル：`.minecraft\config\trade_expansion.json`（サーバーではサーバーの `config` フォルダ）
- Mod Menu と YACL を入れていれば、MOD 一覧の「設定」ボタンから変更できます
- 変えられる主な項目：コインの比率、価格の動き方、相場の戻る速さ、市場の距離、村人の代金の換算、商品ごとの値段、など
