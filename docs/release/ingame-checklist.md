# 公開前のゲーム内確認チェックリスト

開発中に「ゲーム内で確認が必要」とした項目をまとめたものです。各項目は「やること → 期待する結果」の形で書いています。
問題が見つかったら、項目の番号と、どうなったか（スクリーンショットやログ）を教えてください。

## 0. 準備

- 確認に使う jar：`Source/TradeExpansion/build/libs/ak_trade_expansion-<バージョン>.jar`（`build.bat` で作るもの）。配布用 zip（`release.bat` で作る `build/distributions/AKTradeExpansion-<バージョン>.zip`）の中のものでもよい。開発中なら `runClient` でもよい
- **新しいワールド**を作る（村の屋台の建物は、新しく生成される村にしか建たないため）。チートを ON にしておくと便利
- v0.28（バージョン 0.0.17 以降）で Mod ID を `ak_trade_expansion` に変えたため、**それより前のバージョンで作ったワールドは使えない**（コイン・交易所・市場データが消える）。必ず新しいワールドで確認する。設定ファイルも `config/ak_trade_expansion.json` に新しく作られる（古い `trade_expansion.json` は読まない）
- 取引は**サバイバル**で行う（クリエイティブでは取引できない設定が既定）
- お金は `/aktradeex give 10000` で用意できる
- **時間の進め方（大事）**：
  - `/aktradeex market advance <日数>` は、最寄りの市場の**相場と在庫の回復だけ**を進める。市場の時計は進まない
  - 日付や経過時間で決まるもの（本日の掘り出し物の入れ替わり・依頼の期限と入れ替え・預金の利息・市場のレベルの測り直し・品不足の入れ替わり・評判の減り方）を確かめる時は、**設定 `recovery.clock` を `DAY_TIME` にして** `/time add 24000`（ゲーム内1日）を使う。既定の `GAME_TIME` のままだと `/time add` では進まないので、実際に待つ（ゲーム内1日＝現実の20分）
  - 下の項目で「1日たってから」とあるのは、この方法で1日進めること
- 村を探す：`/locate structure minecraft:village_plains`（砂漠・サバンナ・雪原・タイガは `village_desert` などに変える）

## 1. 起動と導入

- [ ] 1-1 Fabric API だけ（Mod Menu・YACL なし）で起動できる → エラーなく起動し、タイトル画面が出る
- [ ] 1-2 Mod Menu・YACL ありで起動できる → Mod 一覧に AK Trade Expansion がアイコン付きで出る
- [ ] 1-3 Mod 一覧の「設定」ボタン → 設定画面が開き、各タブ（通貨・価格・商品・回復・距離・市場・財布・銀行・取引・掲示板/依頼/需要・評判・その他・表示）が表示される
- [ ] 1-4 クリエイティブタブ「AK Trade Expansion」→ 交易所・コイン5種・エメラルド貨・財布・商人のスポーンエッグがある
- [ ] 1-5 コイン・財布・カードにマウスを乗せる → 価値や残高のツールチップが出る

## 2. 交易所と基本の取引

- [ ] 2-1 交易所をクラフトする（カーペット×3／木材・エメラルド・木材／木材・樽・木材）→ 作れる
- [ ] 2-2 交易所を持つ → 画面下に「置くと◯◯に加わる／新しい市場ができる／置けない理由」が1秒ごとに出る
- [ ] 2-3 村の中（村人とベッドがある所）に置く → 置ける。チャットに「この交易所は◯◯に所属しました」
- [ ] 2-4 村人もベッドも無い所に置く → 置けず、理由（今 ベッド◯個・村人◯人）がチャットに出て、交易所が戻る
- [ ] 2-5 既存の市場から 64〜256ブロックの所に置く → 置けない（距離の理由が出る）
- [ ] 2-6 交易所の見た目 → カウンター・柱・縞の日よけ・商品の形。置いた向きに正面（日よけの垂れ・商品側）がプレイヤーを向く
- [ ] 2-7 交易所の当たり判定 → 形どおりに当たる。隣のブロックが透けて見えない（黒くならない）
- [ ] 2-8 右クリック → 交易画面が開く。タイトルが「平原の村 #1（集落）」のような市場名になっている
- [ ] 2-9 購入タブで商品を選び、数量を変える → 合計額が変わる。「最大」で買える最大数になる
- [ ] 2-10 購入する → アイテムが手に入り、所持金が合計額どおり減る。お釣りは財布（無ければコイン）に入る
- [ ] 2-11 同じ商品を続けて買う → 買うたびに値段が上がる。在庫が0になると「売り切れ」「入荷まで約x分」
- [ ] 2-12 売却タブで売る → 所持金が増え、値段が下がる。在庫が上限で「買取停止」
- [ ] 2-13 「売却枠」に品物を置く → 売却タブでその商品が選ばれ、数量が入る。閉じると品物がインベントリに戻る
- [ ] 2-14 Shift を押しながら確定 → できる最大の数量でまとめて取引される
- [ ] 2-15 インベントリをいっぱいにして買う → 入りきらないお釣りが足元に落ちる
- [ ] 2-16 画面を開いたまま交易所から離れる → 画面が閉じる。開いたまま交易所を壊す → 画面が閉じる
- [ ] 2-17 クリエイティブで取引しようとする → 「クリエイティブモードでは取引できません」

## 3. 交易画面の表示

- [ ] 3-1 一覧の ▲▼ → 画面を開いてから値が動いた商品に出る
- [ ] 3-2 一覧右端のメーター → 高い時は右に赤、安い時は左に緑
- [ ] 3-3 商品の行にマウスを乗せる → 直近の価格グラフが出る（数日遊んだ後は線になる）
- [ ] 3-4 所持金の表示 → インベントリの右に「現金」「銀行」。マウスを乗せるとコインの内訳
- [ ] 3-5 設定「表示」タブの所持金の表示位置を「売却枠の下」「右上（タイトル行）」に変える → その位置に表示される。文字が重ならない。「右上」の時、市場名と評判が所持金に重ならない（市場名のほうが縮む）
- [ ] 3-6 タブの文字が枠からはみ出していない、文字や数字が重なっていない
- [ ] 3-7 品不足の商品 → 名前がオレンジ色
- [ ] 3-8 売り切れ・買取停止の商品 → 行が赤みがかった灰色。マウスを乗せると理由と「入荷まで約○分」「買取再開まで約○分」
- [ ] 3-9 買取停止の商品を選ぶ → 右パネルに「買取停止」と「買取再開まで約○分」。その品を売却枠に置く → 売却枠が赤い枠で囲まれる
- [ ] 3-10 購入で数量を16・64にする → 合計の下に「まとめ買い −5%」「−10%」が出て、合計が下がる。確定すると表示どおりの金額で買える（「価格が変わった」にならない）
- [ ] 3-11 所持金ぎりぎりで「最大」を押す → 割引後の金額で買える数になる

## 4. 相場の動き

- [ ] 4-1 売って値を下げた後、`/aktradeex market advance 2` → 値の下がり具合が半分くらい戻る
- [ ] 4-2 128ブロック以上離れた所に2つ目の市場を作り、片方で大量に売る → もう片方の値段も少し下がる（遠いほど小さい）
- [ ] 4-3 取引した後、ワールドを閉じて開き直す → 値段・在庫がそのまま残っている
- [ ] 4-4 食料・松明・原木・花など（消耗品）を上限まで売る → 翌日（約20分後か `advance 1`）には在庫が戻り、また売れる
- [ ] 4-5 `/aktradeex goods set dandelion base_price 10` → タンポポの値段が上がる（画面を開き直すと反映）。`/aktradeex goods reset dandelion` で戻る

## 5. 品揃えと市場の規模

- [ ] 5-1 平原・砂漠・雪原などの村で交易所を開く → 地域ごとに商品が違う（砂漠に砂・サボテン、沼地にヒスイラン など）
- [ ] 5-1b 生の肉（牛・豚・鶏）と生の魚（鱈・鮭）が並ぶ市場がある。焼いた肉は並ばない
- [ ] 5-2 どの市場の売却タブでも（村の外・ネザー・エンドも）エメラルド貨が10枚単位で売れる。何回売っても 10枚で 4c のまま、買取停止にならない。前のバージョンで作った市場にも、画面を開き直すと出る
- [ ] 5-3 ベッドと村人を増やして（例：ベッド20個以上・村人12人以上）、1日たってから交易所を開く → 「市場が◯◯に成長しました」と出て、商品が増える
- [ ] 5-3b ベッドだけ増やして村人が少ないまま → レベルは村人の数で決まり、上がらない（`/aktradeex market info` でベッドと村人の数と測ったレベルを確認）
- [ ] 5-4 市場レベル3以上の市場 → 「銀行」タブが出る。レベル2以下には出ない
- [ ] 5-5 ネザーに村人を連れて行き、交易所を置く → ネザーの商品（クォーツなど）が並ぶ
- [ ] 5-6 ベッドを減らして、1日たってから交易所を開く → 「市場が◯◯に縮小しました」と出て商品が減る。ベッドを戻して1日たってから開く → 同じ商品が、前の値段・在庫のまま戻る
- [ ] 5-7 ★付きの水色の商品（本日の掘り出し物）がある（レベル1〜2で1品、3以上で2品）。1日たってから（`/time add 24000`）開き直す → 別の品に入れ替わる
- [ ] 5-8 レベル4〜5の市場 → ダイヤのツルハシ・斧などの道具、レベル5でダイヤの防具が並ぶことがある。エンチャント付きのダイヤ装備は売れない
- [ ] 5-9 平原の村・開拓地の市場 → シラカバ・ダークオーク・サクラ・ペールオーク・ポプラの原木が並ぶことがある
- [ ] 5-10 確認に使ったワールド（0.0.17 以降で作ったもの）を新しいバージョンの jar で開く → 市場の品揃え・値段・在庫・評判・預金がそのまま残っている（保存データの項目を何度か足したため。0.0.16 以前のワールドは 0章のとおり使えない）

## 6. 村の屋台と商人

- [ ] 6-1 新しく生成された村（平原・砂漠・サバンナ・雪原・タイガ）を探す → 屋台の建物（柵の柱・縞の屋根・交易所・樽・干し草・ランタン）がある村がある
- [ ] 6-2 屋台の建物の向き → 入口（道側）に交易所の正面が向いている。建物が道や家とつながっていて不自然でない
- [ ] 6-3 屋台の建物に商人が立っている → 右クリックで交易画面が開く
- [ ] 6-4 設定 `worldgen.protectNaturalStalls` を ON にして村の交易所を壊す（サバイバル）→ 壊せず「村の交易所は壊せません」
- [ ] 6-5 自分で置いた交易所を開く → 交易所の正面に商人が1体出る。もう一度開いても2体目は出ない
- [ ] 6-6 商人を攻撃する・溶岩に入れる → 死なない。押しても動かない。時間がたっても消えない
- [ ] 6-7 交易所を壊す → その商人も消える
- [ ] 6-8 スポーンエッグ・`/summon ak_trade_expansion:trader` で市場の近くに出す → 右クリックで近くの市場の画面が開く
- [ ] 6-9 市場の無い所でスポーンエッグを使って右クリック → 「近くに市場がありません」
- [ ] 6-10 商人の見た目 → 村人の形に行商人の服。名札を付けられる
- [ ] 6-11 `/kill @e[type=ak_trade_expansion:trader]` → 消える

## 7. 財布・銀行・カード

- [ ] 7-1 財布をクラフト（革×5＋糸×2）→ 作れる

- [ ] 7-4 財布を持って右クリック → 取り出し画面が開き、コインを取り出せる
- [ ] 7-5 財布の残高が容量（20,000c）を超えない
- [ ] 7-6 財布を持って死ぬ → 財布ごと落ちる
- [ ] 7-7 銀行タブで預け入れ・引き出し → 残高が増減する。死んでも銀行の残高は減らない
- [ ] 7-8 カードを発行 → 手数料が口座から引かれ、カードが手に入る

- [ ] 7-10 カードを再発行 → 古いカードは使えない。別のプレイヤーが拾ったカードも使えない

## 8. コインの入手

- [ ] 8-3 作業台で銅ブロック×9 → 銅貨64枚。鉄ブロック×9 → **何もできない**（既定で鉄の鋳造は無効）

- [ ] 8-4 石切台でエメラルドブロック → エメラルド貨1枚

- [ ] 8-6 両替タブ → 「↓」で崩す、「↑」でまとめる。コインの枚数表示が正しい

## 9. 掲示板・依頼・品不足

- [ ] 9-1 掲示板タブ → 近くの市場が「市場名（レベル）・北東 340m」のように出る。選ぶと商品と価格の一覧。一覧の上に「商品／買値／売値」の見出しがあり、列とずれていない。マウスを乗せると買値・売値の説明が出る。下までスクロールすると最後の商品まで見える
- [ ] 9-1b 掲示板の市場一覧 → お買い得のある市場に「安n」（水色）「高n」（桃色）が出る。マウスを乗せると右側に一番お得な品と割合が出る。市場を選ぶと、お買い得の値段が色と矢印で示され、マウスを乗せると割合が出る。文字が重ならない
- [ ] 9-2 依頼タブ → 依頼（品・数・★・報酬）が出る。品を持って「納品する」→ 品が減り、報酬が入る
- [ ] 9-3 依頼の期限（3日）を過ぎる（3日たってから開く）→ 依頼が消え、1日ごとに新しい依頼が出る
- [ ] 9-4 品不足の商品 → 基準より高く買い取られる。3日たつと入れ替わる

## 10. 市場名

## 11. 置き場所の確認

- [ ] 11-0 村人がベッドより多い村（ベッド5個以上）でクラフトした交易所を置く → 新しい市場ができる。ベッド4個以下で村人の方が多い所 → 「またはベッドが5個以上」の理由が出て置けない
- [ ] 11-1 `/aktradeex where` → 村の範囲内か・一番近い市場・ベッドと村人の数・ここに市場を作った場合の規模・置いた時の結果が出る
- [ ] 11-2 `/aktradeex where show` → 30秒間、緑（村の範囲）・黄（同じ市場の範囲）・赤（新しい市場を作れない範囲）・青（数える範囲）の線が地面に出る。見やすい
- [ ] 11-3 設定 `market.newMarketRequires` を VILLAGE / BEDS / VILLAGERS に変えて交易所を置く → それぞれの条件で置ける・置けないが変わる

## 12. 村人・行商人との取引（コイン化）

- [ ] 12-1 村人の取引画面 → エメラルドの上にコインの代金（例：150c）が出る。数字の位置がずれていない
- [ ] 12-2 取引を選ぶ → 支払い欄が空のまま結果欄に品物が出る。取ると所持金が減る
- [ ] 12-3 Shift＋クリックでまとめて買う → お金が尽きるまで買える
- [ ] 12-4 所持金が足りない → 品物が出ない・取れない。支払い欄の下の「代金（所持）」が赤
- [ ] 12-5 支払い欄にエメラルドを置く → コイン化した取引には使われない
- [ ] 12-6 エンチャントの本（エメラルド＋本）・探検家の地図（エメラルド＋コンパス）→ 本・コンパスを支払い欄に置けば買える
- [ ] 12-7 村人に作物を売る取引 → 今までどおりエメラルドがもらえる
- [ ] 12-8 農民のパン → 代金が市場の売値より高い（例：パン6個で 168c 以上）
- [ ] 12-9 村人の近くで `/aktradeex audit villagers` → 儲かる取引が出ない（出るなら品不足の品だけ）
- [ ] 12-10 行商人 → 同じくコインで買える。設定 `villager.wanderingTraderCoins` を OFF にするとエメラルドに戻る（村人はコインのまま）
- [ ] 12-11 設定 `villager.coinTrades` を OFF → 村人もエメラルドの取引に戻る
- [ ] 12-12 村人の値引き（評判を上げる・ゾンビ村人を治す）→ コインの代金も安くなる
- [ ] 12-13 換算（1エメラルド＝30c）が遊んでいて高すぎ・安すぎでないか

## 13. 設定とコマンド

- [ ] 13-1 設定画面で値を変えて保存（シングル）→ すぐ反映される
- [ ] 13-2 マルチに接続中の設定画面 → サーバー側の項目は灰色で変えられない。表示（client）の項目は変えられる
- [ ] 13-3 設定ファイルを編集して `/aktradeex reload` → 反映される
- [ ] 13-4 `/aktradeex consumable add|remove|list`・`/aktradeex goods info|set|reset` → 設定ファイルに保存され、すぐ反映される
- [ ] 13-5 `/aktradeex audit`・`/aktradeex simulate bread buy 10`・`/aktradeex market info` → 結果が出る
- [ ] 13-6 設定画面「商品」タブ →「追加の商品と消耗品」→ 検索でアイテムを探せる。アイコンを選び、基準価格を入れて「追加」→ 登録済みに出る。「完了」で設定ファイルの `goods` に `item` と `base_price` が書かれる
- [ ] 13-7 追加した商品が、いずれかの市場の「本日の掘り出し物」として並び、売買できる
- [ ] 13-8 同じ画面の「消耗品に追加」「消耗品から除外」→ アイコンで追加・削除でき、「完了」で `consumables.add`・`remove` に保存される。`/aktradeex consumable list` に反映される
- [ ] 13-9 すでに商品になっているアイテム（例：パン）を「追加の商品」で追加しようとする → 「すでに商品です」と出て追加されない

- [ ] 25-2 JEI（26.3 版）を入れる → 鉄インゴットなど市場で扱う品で R（レシピ）と U（使い道）のどちらを押しても「市場の相場」のページが出る。屋台のアイコン。市場で扱わない品（岩盤など）には出ない
- [ ] 25-3 25-2 のページ → 近い順に最大5つの市場の名前・方角と距離・買値・売値・在庫が出る。値段は屋台の画面と同じ（評判の割引も入る）。品不足の市場は名前がオレンジ。行にマウスを乗せると市場名と注意（売り切れ・買い取りの上限・何個ずつの取引か）が出る
- [ ] 25-4 ページを開いたまま近くの屋台で売買してから見直す → 数秒のうちに値段が新しくなる
- [ ] 25-5 512 ブロック以内にその品を扱う市場がない場所で開く → 「近くにこの品を扱う市場はありません…」
- [ ] 25-6 屋台（交易所）のアイテムで U → 「市場の相場」の分類が一覧にある（屋台が分類の目印）
- [ ] 25-7 REI（26.3 版）を入れて 25-2〜25-5 → 同じ表示になる
- [ ] 25-8 データパックや `/aktradeex goods` で品を足し・外して `/reload`（または `/aktradeex reload`） → 足した品にページが出る、外した品からは消える
- [ ] 25-9 マルチ：この Mod が入っていないサーバーに入る → ページは出ない。エラーにならない
