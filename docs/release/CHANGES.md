## 未リリース

### 追加
- **商品を50種類追加**（商品は全部で145種類）：
  - **ネザー・エンドの品**：真紅の幹・歪んだ幹・ソウルサンド・ブラックストーン・玄武岩・マグマブロック・シュルームライト、エンドストーン・コーラスフラワー・エンドロッド・ドラゴンブレス・エリトラ。ネザーとエンドの大きな市場でも、市場ごとに品揃えが変わるようになりました
  - **鉄の道具・防具**：鉄のツルハシ・斧・シャベル・ヘルメット・チェストプレート・レギンス・ブーツ、バケツ、ハサミ。鉄の剣とダイヤの品の間の値段です
  - **食料・作物**：生の羊肉・生の兎肉・カボチャ・スイカの薄切り・ビートルート・卵・砂糖・パンプキンパイ・ハチミツ入りの瓶・サトウキビ・氷塊
  - **海の品**：イカスミ・輝くイカスミ・プリズマリンの欠片・オウムガイの殻・海洋の心・トライデント
  - **矢とモブの素材など**：矢・羽根・火打石・クモの目・ウサギの皮・ハニカム・ファントムの皮膜・アルマジロのウロコ・ブリーズロッド・粘土玉・砂利・不死のトーテム
  - どの品も、素材を買ってクラフトして売っても儲からない値段にしています。名札は紙と金属の塊から安く作れるので、商品にしていません
- **海辺の市場**：浜辺や海にプレイヤーが作った市場は「海辺の市場」になり、生鱈・イカスミ・プリズマリンの欠片が安く、オウムガイの殻・海洋の心・トライデントも並びます（村がある場所では村の品揃えが優先されます）
- **村の建物を8種類追加**（建物は全部で14種類）：
  - **時計塔**：金の文字盤と鐘楼の塔。その村では、売り買いで動いた相場が早く元に戻ります
  - **見張り塔**：はしごで上れる見張り台と狼煙の塔。その村を行き来する運び屋の事故が半分になり、商会の動きで相場が動く量も半分になります
  - **酒場**：カウンターと樽の並ぶ店。掲示板に載る村の範囲と数が2倍になります
  - **屋根つき市場**：大屋根の下に露店が並ぶ市場。その村で扱う商品が2つ増えます
  - **港**：事務所・クレーン・桟橋。水辺にだけ建ちます（手前が陸、奥が水の上）。その村が関わる新しい輸送依頼の報酬が1.25倍、運び屋の移動が早くなります
  - **野外劇場**：段々の客席と幕のある舞台。流行の品の値上がりが大きく、余り気味の品の値下がりが小さくなります
  - **温泉**：岩で囲んだ泡の湧く湯船。その村で雇った運び屋は、事故の後の療養が短く、辞めにくくなります
  - **祭りの広場**：やぐら・提灯・露店の広場。5日に1日「祭りの日」になり、その日は評判と発展度が2倍たまります
  - 効果の倍率は設定 `development.clockTowerRecoveryMultiplier`・`watchtowerAccidentMultiplier`・`watchtowerRivalMultiplier`・`tavernBoardMultiplier`・`marketHallExtraGoods`・`harborRewardMultiplier`・`harborTravelMultiplier`・`theaterTrendMultiplier`・`hotSpringRestMultiplier`・`hotSpringQuitMultiplier`・`festivalIntervalDays`・`festivalMultiplier` で変えられます
  - 「発展」タブの建物の一覧は、マウスのホイールでスクロールできます
- **村の娯楽施設（噴水広場・公園）**：村の発展で建てられる建物に、娯楽施設を2つ追加しました。**噴水広場**（11×11）は、光る水盤の真ん中から水が4本に流れ落ちる噴水を、石畳・ベンチ・花壇・街灯が囲む広場で、その村で上がる評判が1.25倍になります。**公園**（13×13）は、生け垣と屋根つきの門の中に、あずまや・木・池・花壇・ベンチがある庭で、その村で貯まる発展度が1.25倍になります。見た目は村の種類ごとに変わります（平原はサクラの木、砂漠はヤシのオアシス、ネザーは溶岩の噴水など）。倍率は設定 `development.fountainReputationMultiplier`・`development.parkPointsMultiplier` で変えられます
- **進捗**：進捗の画面に、この Mod のタブ「商いの始まり」を追加しました（29個）。初めての取引、大口取引、品不足の品を売る、商会の裏をかく、10の市場で取引する、★3の依頼、評判「名士」、運び屋の利益、村に8種類以上の建物をそろえる、10万c をためる、などがあります。達成すると経験値がもらえます。評判・所持金・建物の進捗は、前から遊んでいるワールドでも、ログインした時や交易画面を開いた時に付きます
- **雇い人（運び屋・番頭）**：交易画面に「雇い人」タブを追加しました。その村での評判が「常連」以上なら、村人を雇って留守の間も商売をさせられます（1人で3人まで）。
  - **運び屋**（契約金 300c・給金は往復の利益の2割）：この村で品を仕入れ、ほかの村（2000 ブロック以内）へ運んで売り、戻ってくるのを繰り返します。雇う時に、行き先で高く売れる品を往復ごとに何種類も選ぶ「おまかせ」か、1種類を決めて買値の上限・売値の下限も決める形を選べます。行き先で仕入れ値より高く売れる分だけ仕入れ、差が無い時は待つので、損をしにくくなっています。商人どうしの値段（問屋値）で取引し、相場もあまり動かしません。荷を運ぶ途中で、まれに事故に遭って荷の一部を失います
  - **番頭**（契約金 300c・給金 1日 30c）：預けた品を、決めた値段以上の時だけ、この村で少しずつ売ります。市場が一度に受け付けない分も、留守の間にさばいてくれます
  - 雇った後でも「変更」で扱う品と行き先を選び直せます（持っている品は手元に戻ります。契約金はかかりません）
  - 雇う時に、品ごと・行き先ごとに「今なら1往復でどれくらい儲かるか」と、おすすめの値段が出ます（番頭は1日に売れる額の目安）
  - 雇い人はそれぞれ所持金を持ち、仕入れと給金は所持金から払い、売上は所持金に入ります。お金と品の出し入れ・設定の変更・解雇は雇った村でできます。一覧にはどの村で雇った人も出て、マウスを乗せると様子・売上・最近のできごとが見られます。事故や給金不足はチャットでも知らせます。雇い人の売買で評判と発展度は上がりません
  - 設定（`staff`、設定画面の「雇い人」タブ）：`enabled`、`maxPerPlayer`（人数）、`minReputationLevel`（必要な評判）、`carrierHireFee`・`clerkHireFee`（契約金）、`carrierCommission`（運び屋の歩合）、`carrierWagePerDay`・`clerkWagePerDay`（固定の給金）、`carrierSpreadMultiplier`（問屋値）、`carrierPriceImpact`（運び屋の取引で動く相場）、`carrierCapacity`・`clerkCapacity`（運ぶ数・預かる数）、`carrierBlocksPerDay`（速さ）、`carrierMaxDistance`（行き先の距離）、`carrierMaxWaitDays`（売れ残りを待つ日数）、`accidentBase`・`accidentPerThousandBlocks`・`accidentMax`（事故の確率）、`accidentLossMin`・`accidentLossMax`（失う割合）、`accidentRestDays`（休む日数）、`quitChance`（辞める確率）、`notifyChat`（チャットで知らせる）
  - `staff.enabled` を OFF にすると「雇い人」タブは出ません（まだ雇い人がいる人には、引き取りのために出ます）
  - 管理コマンド：`/aktradeex staff`（全員の雇い人の一覧）、`/aktradeex staff hurry`（次の動きを今にする、テスト用）
- 交易画面のタブの幅を、それぞれの文字の長さに合わせるようにしました
- **JEI・REI との連携**：JEI か REI が入っていると、市場で扱う品で R（レシピ）か U（使い道）を押した時に「市場の相場」のページが出るようになりました。半径512ブロック以内の市場を近い順に5つまで、方角と距離・買値・売値・在庫と一緒に表示します（あなたの評判の割引込みの最新の値段）。どちらも入っていなくても、今までどおり動きます
- **商会の動き**：目に見えない商会（鉄槌商会・豊穣商会・大樹商会・黄昏商会）が、何日かおきに近くの市場で品を買い集めたり（値上がり）売りさばいたり（値下がり）するようになりました。自分が何もしなくても地域の相場が動きます。掲示板の市場一覧の上に「ニュース」として出て、購入・売却の一覧でも、動いている商品にマウスを乗せると分かります。値上がりしている地域へ運んで売る、値下がりしている地域で仕入れる、といった遊び方ができます
  - 設定（`rivals`、設定画面の「掲示板・依頼・需要」タブ）：`enabled`（使うか）、`chancePerDay`（始まる確率）、`maxActive`（同時の数）、`minDays`・`maxDays`（期間）、`minImpact`・`maxImpact`（強さ）、`nearRadius`・`farRadius`（効く範囲）
  - 管理コマンド：`/aktradeex rivals`（一覧）、`/aktradeex rivals start`（今すぐ始める、テスト用）、`/aktradeex rivals clear`（全部消す）
  - データパック：商品グループ（`goods_group`）と商会（`rival_guild`）を足せます
- **村の流行**：村（市場）ごとに、ゲーム内5日ほど続く流行があるようになりました。分野（食料・木材・鉱物・花など11種）ごとに「人気」（基準価格が 1.15〜1.30 倍）と「余り気味」（0.80〜0.90 倍）が選ばれます。交易画面の上の行の「流行」にマウスを乗せると、その村の流行が見られます。掲示板でも、ほかの村の流行が分かります。余り気味の村で仕入れて、人気の村で売ると儲かります
  - 設定（`trend`、設定画面の「掲示板・依頼・需要」タブ）：`durationDays`（期間）、`popularCount`・`unpopularCount`（分野の数。両方 0 で流行なし）、`popularMin`・`popularMax`・`unpopularMin`・`unpopularMax`（倍率）、`minGoods`（候補になる商品数）
- 購入・売却の一覧で、品不足の商品にマウスを乗せると、基準価格の倍率が出るようにしました
- **輸送依頼**：依頼タブに「○○村へ運ぶ」依頼が出るようになりました。保証金（品物の値段）を払って「荷箱」を受け取り、届け先の市場の依頼タブで「荷箱を届ける」を押すと、報酬と保証金が戻ります。遠い村ほど報酬が増え、依頼を出した村と届け先の村の両方で評判が上がります。期限を過ぎると届けられず、保証金は戻りません（受けた村の評判も下がります）
  - 設定（`quest`）：`transportPerMarket`（市場ごとの輸送依頼の数）、`transportMinDistance`・`transportMaxDistance`（届け先までの距離）、`transportBaseMultiplier`・`transportPerThousandBlocks`・`transportMaxMultiplier`（報酬の倍率）
- **村の発展（その1）**：交易画面に「発展」タブを追加しました。村（市場）ごとに、みんなで貯める「発展度」があります。依頼を納める（報酬の半分。輸送依頼は両方の村）、その市場で売り買いする、「発展」タブでコインを寄付すると貯まります。寄付すると、その村での評判も上がります。タブには発展度を多く入れた人（上位5人）と自分の値が出ます。
  - 設定（`development`、設定画面の「村の発展」タブ）：`enabled`（使うか）、`dimensions`（使える次元。既定はオーバーワールド）、`pointsPerCoin`・`questRewardRatio`・`tradePointsPerCoin`（貯まり方）、`halfLifeDays`（減り方。既定は減らない）、`reputationPerPoint`（寄付で上がる評判）など
  - 管理コマンド：`/aktradeex development`（最寄りの市場の発展度）、`/aktradeex development add <発展度>`（テスト用）
- **村の発展（その2）：村の建物**：発展度を使って、村に「依頼所」「倉庫」「宿屋」「銀行」を建てられるようになりました。「発展」タブで建物を選んで「建てる」を押すと、屋台の周りの空き地に足場が立ち、ゲーム内2日で完成します。「杭をもらう」で受け取る「建設予定地の杭」を置くと、そこに建ちます。建物ごとに効果があり（依頼が増える・在庫が増える・村人が来る・銀行が使えて手数料なし）、2つ完成すると市場の規模が1つ、4つで2つ上がります。建てるには、発展度と、建物ごとにほしい資材（例：倉庫は原木256・丸石512・チェスト32）を全部寄付してあることが必要です（寄付した資材は発展度にもなります）。建設中は、その場所にオレンジの点線の枠が出て、木くずが舞い、ときどき作業の音（字幕は「工事の音」）がします。杭を置いた時と右クリックした時に、建物が建つ場所の枠を30秒間表示します（緑は今建てられる、赤は建てられない。チャットに理由）。建物の中の看板を壊すと効果がなくなり、建て直せます。建物の見た目は村の種類（平原・砂漠・サバンナ・雪原・タイガ）ごとに変わります
  - 設定（`development`）：`levelBonusThresholds`（規模が上がる建物の数）、`buildReputationLevel`（建物を選べる評判）、`maxConcurrentBuilds`（同時に建設できる数）、`buildDays`（建設の日数）、`siteRadius`・`siteSearchLimit`（場所探し）、`rebuildCostRatio`（建て直し）、`protectFacilities`（建物を守る）、`materialMultiplier`（資材の寄付で貯まる発展度）、`requireMaterials`（資材を建てる条件にするか）・`materialCountMultiplier`（資材の数の倍率、既定 4.0）、`constructionEffects`（工事中の演出）、各建物の効果（`warehouseStockMultiplier`・`warehouseRestockMultiplier`・`questHallExtraQuests`・`questHallExtraTransport`・`innVillagers`・`bankInterestMaxMultiplier`）
  - 管理コマンド：`/aktradeex development complete`（建設中の建物をすぐ完成させる、テスト用）

### 変更
- **一覧の並び順**：「購入」「売却」タブと「まとめて売る」の商品は値段（基準価格）の安い順に、「発展」タブの建物は必要な発展度の少ない順に並ぶようになりました
- 地域の特産に新しい商品が加わりました（平原：羊肉・カボチャ・ハチミツなど、砂漠：サトウキビ・兎肉、サバンナ：アルマジロのウロコ、雪原：氷塊・兎肉、タイガ：カボチャ・パンプキンパイ、ジャングル：スイカ・羽根、沼地：粘土玉・クモの目、プレイヤーが作った市場：砂利・火打石・バケツ・ハサミ）
- サバンナの村の鞍が1割安くなりました（革が安いので、鞍をクラフトして売ると儲かっていました）
- **村の建物の見た目**：依頼所・倉庫・宿屋・銀行の建物を作り直しました。依頼所・倉庫・宿屋は柱と梁の木組みに、屋根付きの玄関と三角屋根（砂漠は平らな屋根）の家になり、宿屋には煙突が付きます。銀行は柱の並ぶ玄関と石造りの壁、四方に傾いた屋根、窓口のカウンターのある建物になりました。敷地の大きさは今までと同じです（村の種類・ネザー・エンドごとの材料も今までどおり）
- ネザーで倒した敵対モブが、ごくまれに（0.5%）金貨を落とすようになりました
- **掲示板の地図への登録**：市場の一覧の右下に「この市場を登録」（JourneyMap が無い時は「この市場の座標」）を追加し、今いる市場そのものも地図に登録できるようにしました
