# 更新内容

> 使い方：公開したバージョンより後の変更を、遊ぶ人に見える形で「未リリース」に書きためます。
> - 書き方：遊ぶ人向けの言葉で書く（クラス名や内部の話は書かない）。設定を足した時は設定名も書く。
> - 公開前の機能をあとから直した時は、「変更」に分けずに、その機能の「追加」の説明を書き直す。
> - 短い版は [CHANGES-short.md](CHANGES-short.md)（投稿ページの「更新履歴」用）。こちらを直したら、短い版も合わせる。
> - `release.bat` で配布したら、「未リリース」の見出しをそのバージョン番号と日付に書き換え、新しい「未リリース」を上に作る（短い版も同じ）。

## 未リリース

### 追加

- 管理者用のテストのコマンド `/aktradeex clock advance <日数>` を追加しました。すべての市場の時計をまとめて進め、相場と在庫の回復だけでなく、本日の掘り出し物・依頼の期限・品不足・流行・商会の動き・預金の利息・評判の減り方・雇い人・建設も進みます（昼夜や作物は変わりません。戻すことはできません）。`/aktradeex clock` で、今どれだけ進めたかを表示します
- ほかの Mod の作者向けに、取引や相場の変化を受け取ったり、市場と値段を読んだりする仕組み（API）を追加しました（README の「他の Mod から使う」）

### 変更

- 市場がたくさんあるワールドで、取引や近くの市場を探す処理が軽くなりました

### 修正

- JEI・REI などのレシピ表示 Mod で、この Mod のアイテムタグ（消耗品）の名前が翻訳されずに出ていたのを直しました
- 交易画面の購入・売却の一覧で、在庫の数字（「128/128」など）が値段に重なっていたのを直しました（在庫の欄を広げ、入らない時は小さく表示します）
- 依頼タブで、報酬の高い依頼（「25,200c」など）の★が報酬の金額に重なっていたのを直しました

## 0.2.0（2026-11-14）

### 追加

#### 村の発展

交易画面に「**発展**」タブを追加しました。村（市場）ごとに、みんなで貯める「発展度」があり、発展度を使って村に建物を建てられます。

- **発展度の貯め方**：依頼を納める（報酬の半分。輸送依頼は依頼元と届け先の両方の村）、その市場で売り買いする、コインや建物の資材を寄付する。寄付すると、その村での評判も上がります。タブには発展度を多く入れた人（上位5人）と自分の値が出ます
- **建物14種類**：建物ごとに効果があり、2つ完成すると市場の規模が1つ、4つで2つ上がります
  - 依頼所（依頼が増える）・倉庫（在庫が増える）・宿屋（村人が来る）・銀行（どの規模の村でも銀行が使え、カード払いの手数料なし）
  - 噴水広場（その村で上がる評判が1.25倍）・公園（その村で貯まる発展度が1.25倍）
  - 時計塔（売り買いで動いた相場が早く戻る）・見張り塔（運び屋の事故と商会の影響が半分）・酒場（掲示板に載る村の範囲と数が2倍）・屋根つき市場（扱う商品が2つ増える）
  - 港（水辺にだけ建つ。輸送依頼の報酬が1.25倍、運び屋の移動が早くなる）・野外劇場（流行の値上がりが大きく、余り気味の値下がりが小さくなる）・温泉（雇った運び屋の療養が短く、辞めにくくなる）・祭りの広場（5日に1日「祭りの日」になり、評判と発展度が2倍たまる）
- **建て方**：建物を選んで「建てる」を押すと、屋台の周りの空き地に足場が立ち、ゲーム内2日で完成します。建てるには、発展度と、建物ごとにほしい資材（例：倉庫は原木256・丸石512・チェスト32）を全部寄付してあることが必要です。「杭をもらう」で受け取る「建設予定地の杭」を置くと、そこに建ちます。杭を置いた時と右クリックした時に、建つ場所の枠を30秒間表示します（緑は建てられる、赤は建てられない。チャットに理由）
- 建設中は、その場所にオレンジの点線の枠が出て、木くずが舞い、ときどき工事の音（字幕は「工事の音」）がします
- 建物の中の看板を壊すと効果がなくなり、建て直せます
- 建物の見た目は村の種類（平原・砂漠・サバンナ・雪原・タイガ）ごとに変わります（依頼所・倉庫・宿屋は木組みの家、銀行は石造り。噴水広場と公園は、平原ならサクラの木、砂漠ならヤシのオアシス、ネザーなら溶岩の噴水など）
- 「発展」タブの建物は必要な発展度の少ない順に並び、マウスのホイールでスクロールできます。建物を選ぶと、名前の右に大きさ（横×奥行き×高さ）が出ます
- 設定（`development`、設定画面の「村の発展」タブ）
  - 全体：`enabled`、`dimensions`（使える次元。既定はオーバーワールド）
  - 貯まり方：`pointsPerCoin`・`questRewardRatio`・`tradePointsPerCoin`・`materialMultiplier`、`halfLifeDays`（減り方。既定は減らない）、`reputationPerPoint`（寄付で上がる評判）
  - 建て方：`levelBonusThresholds`（規模が上がる建物の数）、`buildReputationLevel`（建物を選べる評判）、`maxConcurrentBuilds`、`buildDays`、`siteRadius`・`siteSearchLimit`、`rebuildCostRatio`、`protectFacilities`（建物を守る）、`requireMaterials`・`materialCountMultiplier`（資材の数の倍率、既定 4.0）、`constructionEffects`（工事中の演出）
  - 建物の効果：`warehouseStockMultiplier`・`warehouseRestockMultiplier`・`questHallExtraQuests`・`questHallExtraTransport`・`innVillagers`・`bankInterestMaxMultiplier`・`fountainReputationMultiplier`・`parkPointsMultiplier`・`clockTowerRecoveryMultiplier`・`watchtowerAccidentMultiplier`・`watchtowerRivalMultiplier`・`tavernBoardMultiplier`・`marketHallExtraGoods`・`harborRewardMultiplier`・`harborTravelMultiplier`・`theaterTrendMultiplier`・`hotSpringRestMultiplier`・`hotSpringQuitMultiplier`・`festivalIntervalDays`・`festivalMultiplier`
- コマンド：`/aktradeex development`（最寄りの市場の発展度）、`/aktradeex development add <発展度>`・`/aktradeex development complete`（テスト用）

#### 雇い人（運び屋・番頭）

交易画面に「**雇い人**」タブを追加しました。その村での評判が「常連」以上なら、村人を雇って留守の間も商売をさせられます（1人で3人まで）。

- **運び屋**（契約金 300c・給金は往復の利益の2割）：この村で品を仕入れ、ほかの村（2000 ブロック以内）へ運んで売り、戻ってくるのを繰り返します
  - 行き先で高く売れる品を往復ごとに何種類も選ぶ「おまかせ」か、1種類を決めて買値の上限・売値の下限も決める形を選べます
  - **帰り荷**：帰りも空では戻らず、行き先の村で「雇った村で高く売れる品」を何種類も自動で選んで仕入れ、戻ってから売ります。行きに運ぶ品が無くても、帰り荷で儲かりそうなら出かけます
  - 仕入れ値より高く売れる分だけ仕入れ、差が無い時は待つので、損をしにくくなっています。商人どうしの値段（問屋値）で取引し、相場もあまり動かしません
  - 荷を運ぶ途中で、まれに事故に遭って荷（帰り荷も）の一部を失います
- **番頭**（契約金 300c・給金 1日 30c）：預けた品を、決めた値段以上の時だけ、この村で少しずつ売ります。市場が一度に受け付けない分も、留守の間にさばいてくれます
- 雇う時に、品ごと・行き先ごとに「今なら1往復でどれくらい儲かるか」（帰り荷の分も含む）と、おすすめの値段が出ます（番頭は1日に売れる額の目安）
- 雇った後でも「変更」で扱う品と行き先を選び直せます（持っている品は手元に戻ります。契約金はかかりません）
- 雇い人はそれぞれ所持金を持ち、仕入れと給金は所持金から払い、売上は所持金に入ります。お金と品の出し入れ・設定の変更・解雇は雇った村でできます。一覧にはどの村で雇った人も出て、マウスを乗せると様子・売上・最近のできごとが見られます。事故や給金不足はチャットでも知らせます。雇い人の売買で評判と発展度は上がりません
- 設定（`staff`、設定画面の「雇い人」タブ）：`enabled`（OFF にするとタブも出ない。まだ雇い人がいる人には引き取りのために出る）、`maxPerPlayer`、`minReputationLevel`、`carrierHireFee`・`clerkHireFee`、`carrierCommission`、`carrierWagePerDay`・`clerkWagePerDay`、`carrierSpreadMultiplier`（問屋値）、`carrierPriceImpact`、`carrierCapacity`・`clerkCapacity`、`carrierBlocksPerDay`、`carrierMaxDistance`、`carrierMaxWaitDays`、`carrierBackhaul`（帰り荷）、`accidentBase`・`accidentPerThousandBlocks`・`accidentMax`、`accidentLossMin`・`accidentLossMax`、`accidentRestDays`、`quitChance`、`notifyChat`
- コマンド：`/aktradeex staff`（全員の雇い人の一覧）、`/aktradeex staff hurry`（次の動きを今にする、テスト用）

#### 輸送依頼

依頼タブに「○○村へ運ぶ」依頼が出るようになりました。保証金（品物の値段）を払って「荷箱」を受け取り、届け先の市場の依頼タブで「荷箱を届ける」を押すと、報酬と保証金が戻ります。遠い村ほど報酬が増え、依頼を出した村と届け先の村の両方で評判が上がります。期限を過ぎると届けられず、保証金は戻りません（受けた村の評判も下がります）。

- 設定（`quest`）：`transportPerMarket`、`transportMinDistance`・`transportMaxDistance`、`transportBaseMultiplier`・`transportPerThousandBlocks`・`transportMaxMultiplier`

#### 村の流行

村（市場）ごとに、ゲーム内5日ほど続く流行があるようになりました。分野（食料・木材・鉱物・花など11種）ごとに「人気」（基準価格が 1.15〜1.30 倍）と「余り気味」（0.80〜0.90 倍）が選ばれます。交易画面の上の行の「流行」にマウスを乗せると、その村の流行が見られ、掲示板ではほかの村の流行も分かります。余り気味の村で仕入れて、人気の村で売ると儲かります。

- 設定（`trend`、設定画面の「掲示板・依頼・需要」タブ）：`durationDays`、`popularCount`・`unpopularCount`（両方 0 で流行なし）、`popularMin`・`popularMax`・`unpopularMin`・`unpopularMax`、`minGoods`

#### 商会の動き

目に見えない商会（鉄槌商会・豊穣商会・大樹商会・黄昏商会）が、何日かおきに近くの市場で品を買い集めたり（値上がり）売りさばいたり（値下がり）するようになりました。自分が何もしなくても地域の相場が動きます。掲示板の市場一覧の上に「ニュース」として出て、購入・売却の一覧でも、動いている商品にマウスを乗せると分かります。

- 設定（`rivals`、設定画面の「掲示板・依頼・需要」タブ）：`enabled`、`chancePerDay`、`maxActive`、`minDays`・`maxDays`、`minImpact`・`maxImpact`、`nearRadius`・`farRadius`
- コマンド：`/aktradeex rivals`（一覧）、`/aktradeex rivals start`（今すぐ始める、テスト用）、`/aktradeex rivals clear`（全部消す）
- データパック：商品グループ（`goods_group`）と商会（`rival_guild`）を足せます

#### 商品を51種類追加（全部で146種類）と海辺の市場

- **ネザー・エンドの品**：真紅の幹・歪んだ幹・ソウルサンド・ブラックストーン・玄武岩・マグマブロック・シュルームライト、エンドストーン・コーラスフラワー・エンドロッド・ドラゴンブレス・エリトラ。ネザーとエンドの大きな市場でも、市場ごとに品揃えが変わるようになりました
- **鉄の道具・防具**：鉄のツルハシ・斧・シャベル・ヘルメット・チェストプレート・レギンス・ブーツ、バケツ、ハサミ。鉄の剣とダイヤの品の間の値段です
- **食料・作物**：生の羊肉・生の兎肉・カボチャ・スイカの薄切り・ビートルート・卵・茶色の卵・青い卵・パンプキンパイ・ハチミツ入りの瓶・サトウキビ・氷塊
- **海の品**：イカスミ・輝くイカスミ・プリズマリンの欠片・オウムガイの殻・海洋の心・トライデント
- **矢とモブの素材など**：矢・羽根・火打石・クモの目・ウサギの皮・ハニカム・ファントムの皮膜・アルマジロのウロコ・ブリーズロッド・粘土玉・砂利・不死のトーテム
- どの品も、素材を買ってクラフトして売っても儲からない値段にしています（名札は紙と金属の塊から安く作れるので、商品にしていません）
- **地域の特産**：平原（羊肉・カボチャ・ハチミツなど）、砂漠（サトウキビ・兎肉・茶色の卵）、サバンナ（アルマジロのウロコ・茶色の卵）、雪原（氷塊・兎肉・青い卵）、タイガ（カボチャ・パンプキンパイ・青い卵）、ジャングル（スイカ・羽根・茶色の卵）、沼地（粘土玉・クモの目）、プレイヤーが作った市場（砂利・火打石・バケツ・ハサミ）
- **海辺の市場**：浜辺や海にプレイヤーが作った市場は「海辺の市場」になり、生鱈・イカスミ・プリズマリンの欠片が安く、オウムガイの殻・海洋の心・トライデントも並びます（村がある場所では村の品揃えが優先されます）

#### 進捗

進捗の画面に、この Mod のタブ「商いの始まり」を追加しました（29個）。初めての取引、大口取引、品不足の品を売る、商会の裏をかく、10の市場で取引する、★3の依頼、評判「名士」、運び屋の利益、村に8種類以上の建物をそろえる、10万c をためる、などがあります。達成すると経験値がもらえます。評判・所持金・建物の進捗は、前から遊んでいるワールドでも、ログインした時や交易画面を開いた時に付きます。

#### JEI・REI との連携

JEI か REI が入っていると、市場で扱う品で R（レシピ）か U（使い道）を押した時に「市場の相場」のページが出るようになりました。半径512ブロック以内の市場を近い順に5つまで、方角と距離・買値・売値・在庫と一緒に表示します（あなたの評判の割引込みの最新の値段）。どちらも入っていなくても、今までどおり動きます。

### 変更

- **本日の掘り出し物**に高い品が出すぎないようにしました。市場の規模に見合う品だけが選ばれ（小さな集落にエリトラやダイヤの防具は並びません。ダイヤの防具はレベル5の市場から）、高い品ほどまれにしか出ません。設定 `market.specialUseGrade`（規模に合わせるか）と `market.specialPriceExponent`（高い品の出にくさ、0 で今までと同じ確率）で変えられます
- 「購入」「売却」タブと「まとめて売る」の商品が、値段（基準価格）の安い順に並ぶようになりました
- 掲示板の市場の一覧の右下に「この市場を登録」（JourneyMap が無い時は「この市場の座標」）を追加し、今いる市場そのものも地図に登録できるようにしました
- 購入・売却の一覧で、品不足の商品にマウスを乗せると、基準価格の倍率が出るようにしました
- 交易画面のタブの幅を、それぞれの文字の長さに合わせるようにしました
- ネザーで倒した敵対モブが、ごくまれに（0.5%）金貨を落とすようになりました
- サバンナの村の鞍が1割安くなりました（革が安いので、鞍をクラフトして売ると儲かっていました）
- **商人の服の色**が8種類（青・赤・緑・紫・茶・青緑・灰・黒）になりました。商人が現れた時にランダムで決まります。前からいる商人も、次に読み込まれた時に色が決まります

### 修正

- マルチプレイで、両替タブの「手数料 ◯%」がサーバーの設定ではなく自分の設定の値で表示されていたのを直しました（実際の手数料は前からサーバーの値です）
