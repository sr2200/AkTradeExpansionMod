# 更新内容

> 使い方：公開したバージョンより後の変更を、遊ぶ人に見える形で「未リリース」に書きためます。
> - 書き方：遊ぶ人向けの言葉で書く（クラス名や内部の話は書かない）。設定を足した時は設定名も書く。
> - 公開前の機能をあとから直した時は、「変更」に分けずに、その機能の「追加」の説明を書き直す。
> - 短い版は [CHANGES-short.md](CHANGES-short.md)（投稿ページの「更新履歴」用）。こちらを直したら、短い版も合わせる。
> - `release.bat` で配布したら、「未リリース」の見出しをそのバージョン番号と日付に書き換え、新しい「未リリース」を上に作る（短い版も同じ）。

## 未リリース

### 追加

- 村の発展の建物に「**鋳造所**」を追加しました（15種類目）。鋳造所のある村では、交易画面の「両替」タブで銅ブロック9個を 96c 分のコインに鋳造できます（作業台の鋳造の1.5倍）。鉄ブロック9個は 960c 分で、作業台と同じく設定 `currency.allowIronMinting` を ON にした時だけ使えます。倍率は設定 `development.mintValueMultiplier` で変えられます。鋳造所の看板を右クリックすると「両替」タブが開きます
- **交易路**と新しいブロック「**道標**」（銅インゴット・ランタン・看板・柵でクラフト。ランタンと同じ明るさで光ります）を追加しました。2つの市場の間に道標を64ブロック以内ごとに並べ、両端をそれぞれの市場の中心から64ブロック以内に置くとつながり、遠く離れていても相場の変化の少なくとも半分が伝わるようになります。1つの市場の交易路は4本までです。道標を右クリックすると、その道がどの市場につながっているかが分かります。設定 `route.enabled`・`route.signpostSpacing`・`route.roadWeight`・`route.maxRoutesPerMarket`（設定画面の「距離」）
- 襲撃者の旗持ち（不吉な旗をかぶった隊長）をプレイヤーが倒すと、75% の確率で金貨（100c）を1枚落とすようにしました（ネザー以外でも）
- **品不足を満たすと村が育つ**ようにしました。品不足の期間（3日）のうちにその品を16個売ると（何人で売っても合わせて数えます。雇った運び屋が行き先で売った分も数えます）、その品不足は終わり、村に発展度のおまけ（その品の基準価格 × 16）が入ります。品不足を3回満たすごとに、空いたベッドがあれば村人が1人やって来ます（ネザー・エンドでは来ません）。品不足の商品にマウスを乗せると、あと何個で満たせるかが出ます。
- 村に「**元気**」（0〜100）を追加しました。品不足を満たすと大きく上がり、その村で売り買いや依頼の納品をしても少しずつ上がります（1,000c の取引で +1）。満たさないまま期間が終わると少し下がりますが、売った分だけ下がり方が軽くなります（16個中8個売っていれば半分）。元気が50より低い村は、放っておいても1日に2ずつ50まで戻ります。元気が50より低いと、その村で貯まる発展度が少し減ります（元気0で 0.9 倍）。「発展」タブの上の行に出て、マウスを乗せると満たした回数と、あと何回で村人が来るかが出ます。設定 `demand.fulfillCount`・`demand.fulfillPointsRatio`・`demand.villagersEvery`・`demand.vigorGain`・`demand.vigorLoss`・`demand.vigorPenalty`・`demand.vigorPerPoint`・`demand.vigorRecoverPerDay`
- 村の発展の建物を8種類追加しました（全部で23種類）。どれも村のそれぞれの仕組みに効きます。設定画面の「村の発展」で倍率などを変えられます
  - **駅舎**：この村は交易路を6本まで持てて（ふつうは4本）、この村につながる交易路では相場の変化の75%が伝わります（道だけなら50%）。設定 `development.stationExtraRoutes`・`development.stationRoadWeight`
  - **目利きの店**：本日の掘り出し物が1つ増え（次の日から）、掘り出し物の値段の上乗せ（1.2倍）が無くなります。設定 `development.appraiserExtraSpecials`・`development.appraiserSpecialPriceMultiplier`
  - **問屋**：品不足が1つ増え（次の入れ替えから）、品不足を満たした時のおまけの発展度が1.5倍になります。設定 `development.wholesalerExtraShortages`・`development.wholesalerFulfillMultiplier`
  - **商人組合の会館**：この村で雇った番頭が、同じ下限までに1.5倍売れるようになり、給金（売上の歩合）が0.75倍になります。設定 `development.guildHallClerkSpeedMultiplier`・`development.guildHallClerkWageMultiplier`
  - **礼拝堂**：この村での評判が時間で減る速さが半分になります。設定 `development.chapelReputationDecayMultiplier`
  - **村役場**：この村のほかの建物を建てるのに要る資材が0.75倍になります。設定 `development.townHallMaterialMultiplier`
  - **職人の工房**：この村の近くの村人との交易が0.9倍のコインでできます（近くの市場の買値より安くはなりません）。設定 `development.workshopVillagerPriceMultiplier`
  - **学舎**：交易画面の品不足・流行の品にマウスを乗せると「あと何日で入れ替わるか」が出ます。雇い人タブで品を決めた運び屋の行き先にマウスを乗せると、行き先の品不足・流行・商会の動きと、それがあと何日続くかが出ます
- **商人の手帳**を追加しました（作業台で本と銅貨1枚）。右クリックで開くと、「今日」に今日の売上・仕入れ・利益・依頼の報酬・雇い人の稼ぎと、よく儲かった品が、「昨日」に昨日の同じ数字とよく儲かった品が、「日ごと」にこの1週間の毎日の数字と合計が出ます。利益は、売った額からその品を市場で買った時の値段を引いたものです（自分で集めた品・作った品は全部が利益）。「価格メモ」には、交易画面を開いた市場の買値・売値が最近の16市場まで自動で書き留められ、品ごとに市場を並べて、どこで買ってどこで売ると儲かるかが分かります。「雇い人」には、自分の雇い人全員の品・行き先・所持金・様子が出て、どこにいても様子が分かります（マウスを乗せるとこれまでの売上・最近のできごと）。手帳は書見台に置くこともでき、置いた手帳を右クリックすると、開いた人の帳簿が出ます（「書見台から取る」で取り出せます）。設定 `notebook.keepDays`・`notebook.priceNotes`（設定画面の「商人の手帳」）
- **天気で相場が動く**ようにしました（オーバーワールドの市場だけ）。今日と前の2日に合わせて1日分以上雨が降ると、作物（小麦・ニンジン・ジャガイモ・ビートルート・カボチャ・スイカの薄切り・サトウキビ・スイートベリー・カカオ豆）の基準価格が 0.85 倍になり、始まった時・終わった時にチャットで知らせます（交易画面の行にマウスを乗せると「雨続きで作物が安い」）。雷雨の間に荷箱を届けると、輸送の報酬が 1.5 倍になります（雷雨が始まった時、荷箱を持っていれば知らせます）。設定 `weather.enabled`・`weather.rainDays`・`weather.rainMultiplier`・`weather.stormRewardMultiplier`・`weather.notifyChat`（設定画面の「掲示板・依頼・需要」）。雨で安くなる品はデータパック（`rain_goods`）で変えられます
- **市場イベント**を追加しました。「豊作」「不作」「鉱山の事故」「新しい鉱脈」「大漁」「山火事」「村の祭り」「砦の崩落（ネザーだけ）」の8種類の出来事が、何日か（2〜5日）だけ中心の市場の周りの品の値段を 0.65〜1.6 倍に動かします（1日目は3分の1、3日目から全部効き、中心から遠いほど弱く、640 ブロックより遠い市場には効きません。終わった日に元の値段に戻ります）。始まる前の日に掲示板とチャットで「予報」が出るので、先に仕入れたり売るのを待ったりできます。掲示板のニュースの一番上に「【豊作】小麦・パンなどが安い　北東 340m　あと3日」のように出て、交易画面の行にもマウスを乗せると出ます。イベントで動いている品は品不足や商会の動きには選ばれません。品不足・流行・雨・イベント・掘り出し物が重なっても、基準価格は 0.4〜2.5 倍の間に収まります。イベントはデータパック（`market_event`）で足したり止めたりできます。設定 `events.enabled`・`events.priceUp`・`events.priceDown`・`events.forecast`・`events.notifyChat`・`events.otherDimensions`・`events.chancePerDay`・`events.maxActive`・`events.nearRadius`・`events.farRadius`・`events.strength`。管理者用のコマンド `/aktradeex events`（一覧）・`/aktradeex events start [<イベント>]`・`/aktradeex events clear`
- **朝の日報**を追加しました。朝（日が昇った時・寝て起きた時）に、前の日に売り買いしていれば、昨日の売上・仕入れ・利益、いちばん儲かった品、雇い人の稼ぎ、依頼の報酬をチャットで知らせます。何日か遊ばなかった後はその間をまとめて知らせます。商人の手帳の「朝の日報：受け取る」で止められます。設定 `notebook.dailyReport`
- 運び屋の行き先に「**毎回選ぶ**」を追加しました。出かけるたびに、近くの4か所の村から、その時いちばん儲かる村（往復の時間あたり）へ行きます。品不足や流行の村を見つけやすく、行き先を1つに決めるより儲かります（行き先の一覧の先頭。おまかせでも品を決めた運び屋でも選べます）。設定 `staff.carrierRoamChoices`
- 品を決めた運び屋が1日儲からない（雇った時の値段の差が消えた）と、チャットとログで一度知らせるようにしました。右パネルの「**おまかせ**」ボタンで、行き先と運ぶ数はそのままおまかせに切り替えられます。設定 `staff.noMarginNoticeDays`
- 雇い人が、雇った村の市場の近くに**村人の姿**で立つようにしました（頭の上に「○○の運び屋（鉄インゴット）」の名前。運び屋は出かけている間はいません）。話しかけると、その雇い人を選んだ「雇い人」タブが開きます（ほかの人の雇い人は開きません）。設定 `staff.showEmployees`
- 1つの村で全員の雇い人が1日に売り買いできる数に上限（2,048）を付けました。超えると様子が「混雑」になり、次の日まで待ちます。大勢が雇うサーバーで相場が動きすぎないためで、ふつうは届きません。設定 `staff.marketDailyUnits`（0 で上限なし）
- 村の建物に**段階**（Lv2・Lv3）を追加しました。完成した建物は「発展」タブで発展度と資材を払うと Lv2・Lv3 に上がり（費用は建てる時の同じだけ・1.5倍）、効果が強くなります（Lv2 で 1.5 倍、Lv3 で 2 倍の強さ。例：倉庫の在庫の上限 1.5倍 → 1.75倍 → 2倍、依頼所の依頼 +2 → +3 → +4）。Lv2 に上げる時に2つの**方向**から選び（例：宿屋の「大部屋」は来る村人が多く、「上等な宿」はこの村の評判が上がりやすい）、選んだ方の効果がよく伸びます。見た目も立派になり（旗・植木鉢・ランタン。2つ目の方向を選ぶと旗の色が変わり、依頼所・噴水広場・屋根つき市場・港・温泉は吊り看板・灯りの柱・入り口の門など建物ごとの飾りも増えます）、Lv3 は上が空いていれば12種類の建物が2階建てになり（中の階段で2階に上がれます。依頼所ははしご）、ほかの11種類は高い形（礼拝堂の鐘楼・駅舎の時計の小塔・2段の噴水・時計塔の回廊と尖塔・高い見張り塔・公園と屋根つき市場の灯りの塔・港の灯りの部屋・野外劇場の高い舞台・温泉の湯船の屋根・祭りの2段のやぐら）になります。進捗「普請」「二階建て」「立派な村」も足しました。工事の間も効果は続き、中のチェストの中身はなくなりません。壊れた建物は段階のまま、合計の費用の半分で建て直せます。設定 `development.upgradeEnabled`・`development.upgradeCostMultipliers`・`development.upgradeEffectSteps`・`development.upgradePerkBonus`
- ほかの Mod の作者・データパックを作る人向けの仕組み（API）を広げました：雇い人の売買と依頼の納品を受け取れるように、ほかの Mod の店の売買を相場に反映したり、口座と財布のお金を出し入れしたりできるようにしました。データパックで、すでにある村の品揃え（市場プロファイル）に品と値段の倍率を足せるようになりました（`market_profile_addition`。値段の倍率は商品ごとにも指定できます）。ほかの Mod が、1つずつ中身の違う品（品種の花の株など）を「この商品として何倍の値段で買い取るか」決められるようにしました。こうした品は交易画面の「売る」・まとめて売る・売却スロットで売れ、1個ずつ違う値段（高い品から先に売れます）がプレビューに出ます（README の「他の Mod から使う」）

### 変更

- 設定画面の「追加の商品と消耗品」で、アイテムの一覧と登録済みの一覧の右にスクロールバーを付けました（つまみのドラッグ・溝のクリックでも動かせます）。登録済みの一覧は1度に32個まで見えるようになり、追加した品が見える所まで自動で動きます。「追加の商品」でアイテムを選ぶと、**推奨の基準価格**が入るようになりました。作れる品はレシピと材料の商品の値段から（2種類以上の材料を組み合わせる品は材料の合計の約1.25倍）、作れない品・材料の値段が分からない品はレア度・スタック数・食べ物・耐久値からの目安です。入った値は直してから「追加」できます
- 噴水広場の水が、受け皿の左右の2本だけに流れ落ちるようにしました（前は4本で、受け皿が水に隠れていました）。正面から受け皿が見えます。これから建てる噴水と、段階を上げた噴水がこの形になります
- 番頭の給金を「品を預かっている日ごとに 30c」から「**売上の1割**」（売れた時に売上から引く。売れない日はかかりません）にしました。パンや小麦など安い品を預けても給金で儲けが消えなくなります。また、番頭が1個売っても値をあまり下げないようにし、約2倍の速さで売れるようになりました（鉄インゴット64個なら約12日で売り切ります）。設定 `staff.clerkCommission`・`staff.clerkPriceImpact`。固定の給金 `staff.clerkWagePerDay` の既定は 0 になりました
- 運び屋の問屋値を少し控えめにしました（買値と売値の差が半分 → 6割、相場を動かす量が 0.25 → 0.35）。プレイヤーが自分で運ぶより得になりすぎないためで、儲けは1〜2割ほど下がります。設定ファイルに前の既定値（`staff.carrierSpreadMultiplier` 0.5・`staff.carrierPriceImpact` 0.25・`staff.clerkWagePerDay` 30）が書かれたままなら、新しい既定値として読みます（手で変えた値はそのままです）
- Mod のレシピがレシピ本に最初から出ないようにし、材料などを手に入れた時に解禁されるようにしました。財布は革か銅貨、交易所はエメラルドか樽、道標は交易所かランタン、銅貨の鋳造は銅ブロック、エメラルド貨（石切台）はエメラルドブロック、鉄貨の鋳造は鉄ブロック（設定で ON の時だけ）を持つと解禁されます
- 管理者用のコマンド `/aktradeex market reroll` で、同じ市場でも選び直すたびに品揃えが変わるようにしました（今までは同じ場所の市場では毎回同じ品揃えになっていました。一度も選び直していない市場の品揃えは変わりません）
- 交易画面を開いたままウィンドウを小さくして画面が入らなくなった時、その場で入る大きさに縮むようにしました（今までは開き直すまで画面からはみ出していました。大きくした時は、開き直すと広がります）
- 管理者が `/aktradeex market delete` で市場を消した時、その市場の交易画面を開いている人の画面を閉じ、「この市場はなくなりました」と知らせるようにしました（今までは開いたまま買おうとすると「不正な操作です」と出ていました）
- 商会の動きが、最近（今日を含めて3日以内）プレイヤーが交易画面や掲示板を開いた市場の近く（512 ブロック以内）で起きるようにしました。今までは全部の市場から同じ確率で選んでいたので、広いワールドでは遊んでいる場所の近くでめったに起きませんでした（最近だれも来ていない時は今までどおり全部の市場から選びます）
- いくつかの素材を組み合わせて作る品の値段を上げ、素材のまま売るより作って売るほうが儲かるようにしました（素材の合計の約 1.25 倍）：金のニンジン 70→95c、金のリンゴ 450→800c、パンプキンパイ 20→25c、松明 2→3c、矢 2→2.5c、弓 14→19c、盾 78→90c、白色のベッド 44→52c、本 32→44c、鞍 130→150c、エンダーアイ 80→112c、マグマクリーム 25→70c、エンドロッド 15→20c。同じ市場で素材を買って作って売っても儲からない値段にしてあります。パン・ガラス・防具のように1種類の素材から作る品は変えていません
- 運び屋が空荷で帰り荷のために出かける時、ログに「空荷で「…」へ出発（帰り荷のため）」の行を出すようにしました
- 建設予定地の杭を置いた時はチャットに何も出さず（建つ場所の枠だけ出ます）、杭を右クリックした時にだけ、建物ごとの「建てられます／建てられません：理由」や「市場がありません」をチャットに出すようにしました
- 村の建物のうち石造りの建物（銀行・鋳造所・商人組合の会館・村役場・駅舎）の見た目を良くしました。木組みの家と同じく屋根が横の壁より外に張り出し、その下に柱と窓の下の石の縁、入り口の前に段、扉の上に金のブロック（会館はエメラルド、鋳造所は銅）。銀行は4本の柱の上に三角の破風、村役場は屋根の上に鐘の小さな塔、鋳造所は平らな屋根から煙突が出ます（中の部屋は少し狭くなりました）。宿屋の玄関に吊り看板と屋根の正面の扉、学舎の屋根に鐘、目利きの店の窓の前に陳列台も付けました
- 村の建物のうち木組みの家（依頼所・倉庫・宿屋・酒場・目利きの店・問屋・職人の工房・学舎）の見た目を良くしました。屋根が横の壁より外に張り出し（大きめの家）、軒の下に植え込みと開いた雨戸、屋根の端とてっぺんを濃い色の材料にし、煙突は外の壁に沿って立ち上がります。倉庫には荷揚げの扉と滑車、問屋・酒場・職人の工房には軒の下に樽や薪が置かれ、外から何の建物か分かりやすくなりました。砂漠の家は屋根の梁の端が突き出します。敷地の大きさは変わりません（大きめの家は中の部屋が少し狭くなります）。すでに建っている建物は変わらず、新しく建てた時（建て直した時）からこの見た目になります

## 0.3.0（2026-11-21）

### 追加

- 管理者用のテストのコマンド `/aktradeex clock advance <日数>` を追加しました。すべての市場の時計をまとめて進め、相場と在庫の回復だけでなく、本日の掘り出し物・依頼の期限・品不足・流行・商会の動き・預金の利息・評判の減り方・雇い人・建設も進みます（昼夜や作物は変わりません。戻すことはできません）。`/aktradeex clock` で、今どれだけ進めたかを表示します
- ほかの Mod の作者向けに、取引や相場の変化を受け取ったり、市場と値段を読んだりする仕組み（API）を追加しました（README の「他の Mod から使う」）

### 変更

- 消耗品（上限まで売っても在庫が1日で戻り、値段も早く戻る品）を見直しました。砂利・粘土玉・砂岩・氷・サボテン・スイレンの葉・ネザーウォート・ソウルサンド・ブラックストーン・玄武岩・エンドストーンを消耗品に加え、高級品のトーチフラワー・ウツボカズラ・ウィザーローズを外しました（金のニンジン・金のリンゴと同じく、ふつうの速さで戻ります）。設定 `consumables.add`・`consumables.remove` か `/aktradeex consumable` で元に戻すこともできます
- 交易画面の「流行」を、画面の右上から評判のすぐ後ろ（「市場名 │ 評判：常連 │ 流行」）に移しました。設定 `client.trendPosition` で、元の位置（タイトル行の右端）や一覧の下の状態表示の行にも変えられます
- 市場がたくさんあるワールドで、取引や近くの市場を探す処理が軽くなりました
- 村の発展で建物を建てる場所を探す範囲が、市場レベルが上がるほど広がるようにしました（既定ではレベル1で32ブロック、レベル3で48、レベル5で64）。設定 `development.siteRadiusPerLevel` で広がり方を変えられます。また、これまでは範囲の内側の一部（屋台から20ブロックほど）しか探していなかったので、範囲の中を全部探すようにしました（設定 `development.siteSearchLimit` の既定を 4096 に。前の版の設定ファイルに残っている 256 も 4096 として読みます）。建設予定地の杭も、広がった範囲の中なら置けます

### 修正

- JEI・REI などのレシピ表示 Mod で、この Mod のアイテムタグ（消耗品）の名前が翻訳されずに出ていたのを直しました

## 0.2.0（2026-11-14）

### 追加

#### 村の発展

交易画面に「**発展**」タブを追加しました。村（市場）ごとに、みんなで貯める「発展度」があり、発展度を使って村に建物を建てられます。

- **発展度の貯め方**：依頼を納める（報酬の半分。輸送依頼は依頼元と届け先の両方の村）、その市場で売り買いする、コインや建物の資材を寄付する。寄付すると、その村での評判も上がります。タブには発展度を多く入れた人（上位5人）と自分の値が出ます
- **建物14種類**：建物ごとに効果があり、2つ完成すると市場の規模が1つ、4つで2つ上がります
  - 依頼所（依頼が増える）・倉庫（在庫が増える）・宿屋（村人が来る）・銀行（どの規模の村でも銀行が使え、カード払いの手数料なし）
  - 噴水広場（その村で上がる評判が1.25倍）・公園（その村で貯まる発展度が1.25倍）
  - 時計塔（売り買いで動いた相場が早く戻る）・見張り塔（運び屋の事故と商会の影響が半分）・酒場（掲示板に載る村の範囲と数が2倍）・屋根つき市場（扱う商品が2つ増える）
  - 港（水辺にだけ建つ。輸送依頼の報酬が1.25倍、運び屋の移動が早くなる）・野外劇場（流行の値上がりが大きく、余り気味の値下がりが小さくなる）・温泉（雇った運び屋の療養が短く、辞めにくくなる）・祭りの広場（5日に1日「祭りの日」になり、評判と発展度が2倍たまる）
- **建て方**：建物を選んで「建てる」を押すと、屋台の周りの空き地に足場が立ち、ゲーム内2日で完成します。建てるには、発展度と、建物ごとにほしい資材（例：倉庫は原木256・丸石512・チェスト32）を全部寄付してあることが必要です。「杭をもらう」で受け取る「建設予定地の杭」を置くと、そこに建ちます。杭を置いた時と右クリックした時に、建つ場所の枠を30秒間表示します（緑は建てられる、赤は建てられない。チャットに理由）
- 建設中は、その場所にオレンジの点線の枠が出て、木くずが舞い、ときどき工事の音（字幕は「工事の音」）がします
- 建物の中の看板を壊すと効果がなくなり、建て直せます
- 建物の見た目は村の種類（平原・砂漠・サバンナ・雪原・タイガ）ごとに変わります（依頼所・倉庫・宿屋は木組みの家、銀行は石造り。噴水広場と公園は、平原ならサクラの木、砂漠ならヤシのオアシス、ネザーなら溶岩の噴水など）
- 「発展」タブの建物は必要な発展度の少ない順に並び、マウスのホイールでスクロールできます。建物を選ぶと、名前の右に大きさ（横×奥行き×高さ）が出ます
- 設定（`development`、設定画面の「村の発展」タブ）
  - 全体：`enabled`、`dimensions`（使える次元。既定はオーバーワールド）
  - 貯まり方：`pointsPerCoin`・`questRewardRatio`・`tradePointsPerCoin`・`materialMultiplier`、`halfLifeDays`（減り方。既定は減らない）、`reputationPerPoint`（寄付で上がる評判）
  - 建て方：`levelBonusThresholds`（規模が上がる建物の数）、`buildReputationLevel`（建物を選べる評判）、`maxConcurrentBuilds`、`buildDays`、`siteRadius`・`siteSearchLimit`、`rebuildCostRatio`、`protectFacilities`（建物を守る）、`requireMaterials`・`materialCountMultiplier`（資材の数の倍率、既定 4.0）、`constructionEffects`（工事中の演出）
  - 建物の効果：`warehouseStockMultiplier`・`warehouseRestockMultiplier`・`questHallExtraQuests`・`questHallExtraTransport`・`innVillagers`・`bankInterestMaxMultiplier`・`fountainReputationMultiplier`・`parkPointsMultiplier`・`clockTowerRecoveryMultiplier`・`watchtowerAccidentMultiplier`・`watchtowerRivalMultiplier`・`tavernBoardMultiplier`・`marketHallExtraGoods`・`harborRewardMultiplier`・`harborTravelMultiplier`・`theaterTrendMultiplier`・`hotSpringRestMultiplier`・`hotSpringQuitMultiplier`・`festivalIntervalDays`・`festivalMultiplier`
- コマンド：`/aktradeex development`（最寄りの市場の発展度）、`/aktradeex development add <発展度>`・`/aktradeex development complete`（テスト用）

#### 雇い人（運び屋・番頭）

交易画面に「**雇い人**」タブを追加しました。その村での評判が「常連」以上なら、村人を雇って留守の間も商売をさせられます（1人で3人まで）。

- **運び屋**（契約金 300c・給金は往復の利益の2割）：この村で品を仕入れ、ほかの村（2000 ブロック以内）へ運んで売り、戻ってくるのを繰り返します
  - 行き先で高く売れる品を往復ごとに何種類も選ぶ「おまかせ」か、1種類を決めて買値の上限・売値の下限も決める形を選べます
  - **帰り荷**：帰りも空では戻らず、行き先の村で「雇った村で高く売れる品」を何種類も自動で選んで仕入れ、戻ってから売ります。行きに運ぶ品が無くても、帰り荷で儲かりそうなら出かけます
  - 仕入れ値より高く売れる分だけ仕入れ、差が無い時は待つので、損をしにくくなっています。商人どうしの値段（問屋値）で取引し、相場もあまり動かしません
  - 荷を運ぶ途中で、まれに事故に遭って荷（帰り荷も）の一部を失います
- **番頭**（契約金 300c・給金 1日 30c）：預けた品を、決めた値段以上の時だけ、この村で少しずつ売ります。市場が一度に受け付けない分も、留守の間にさばいてくれます
- 雇う時に、品ごと・行き先ごとに「今なら1往復でどれくらい儲かるか」（帰り荷の分も含む）と、おすすめの値段が出ます（番頭は1日に売れる額の目安）
- 雇った後でも「変更」で扱う品と行き先を選び直せます（持っている品は手元に戻ります。契約金はかかりません）
- 雇い人はそれぞれ所持金を持ち、仕入れと給金は所持金から払い、売上は所持金に入ります。お金と品の出し入れ・設定の変更・解雇は雇った村でできます。一覧にはどの村で雇った人も出て、マウスを乗せると様子・売上・最近のできごとが見られます。事故や給金不足はチャットでも知らせます。雇い人の売買で評判と発展度は上がりません
- 設定（`staff`、設定画面の「雇い人」タブ）：`enabled`（OFF にするとタブも出ない。まだ雇い人がいる人には引き取りのために出る）、`maxPerPlayer`、`minReputationLevel`、`carrierHireFee`・`clerkHireFee`、`carrierCommission`、`carrierWagePerDay`・`clerkWagePerDay`、`carrierSpreadMultiplier`（問屋値）、`carrierPriceImpact`、`carrierCapacity`・`clerkCapacity`、`carrierBlocksPerDay`、`carrierMaxDistance`、`carrierMaxWaitDays`、`carrierBackhaul`（帰り荷）、`accidentBase`・`accidentPerThousandBlocks`・`accidentMax`、`accidentLossMin`・`accidentLossMax`、`accidentRestDays`、`quitChance`、`notifyChat`
- コマンド：`/aktradeex staff`（全員の雇い人の一覧）、`/aktradeex staff hurry`（次の動きを今にする、テスト用）

#### 輸送依頼

依頼タブに「○○村へ運ぶ」依頼が出るようになりました。保証金（品物の値段）を払って「荷箱」を受け取り、届け先の市場の依頼タブで「荷箱を届ける」を押すと、報酬と保証金が戻ります。遠い村ほど報酬が増え、依頼を出した村と届け先の村の両方で評判が上がります。期限を過ぎると届けられず、保証金は戻りません（受けた村の評判も下がります）。

- 設定（`quest`）：`transportPerMarket`、`transportMinDistance`・`transportMaxDistance`、`transportBaseMultiplier`・`transportPerThousandBlocks`・`transportMaxMultiplier`

#### 村の流行

村（市場）ごとに、ゲーム内5日ほど続く流行があるようになりました。分野（食料・木材・鉱物・花など11種）ごとに「人気」（基準価格が 1.15〜1.30 倍）と「余り気味」（0.80〜0.90 倍）が選ばれます。交易画面の上の行の「流行」にマウスを乗せると、その村の流行が見られ、掲示板ではほかの村の流行も分かります。余り気味の村で仕入れて、人気の村で売ると儲かります。

- 設定（`trend`、設定画面の「掲示板・依頼・需要」タブ）：`durationDays`、`popularCount`・`unpopularCount`（両方 0 で流行なし）、`popularMin`・`popularMax`・`unpopularMin`・`unpopularMax`、`minGoods`

#### 商会の動き

目に見えない商会（鉄槌商会・豊穣商会・大樹商会・黄昏商会）が、何日かおきに近くの市場で品を買い集めたり（値上がり）売りさばいたり（値下がり）するようになりました。自分が何もしなくても地域の相場が動きます。掲示板の市場一覧の上に「ニュース」として出て、購入・売却の一覧でも、動いている商品にマウスを乗せると分かります。

- 設定（`rivals`、設定画面の「掲示板・依頼・需要」タブ）：`enabled`、`chancePerDay`、`maxActive`、`minDays`・`maxDays`、`minImpact`・`maxImpact`、`nearRadius`・`farRadius`
- コマンド：`/aktradeex rivals`（一覧）、`/aktradeex rivals start`（今すぐ始める、テスト用）、`/aktradeex rivals clear`（全部消す）
- データパック：商品グループ（`goods_group`）と商会（`rival_guild`）を足せます

#### 商品を51種類追加（全部で146種類）と海辺の市場

- **ネザー・エンドの品**：真紅の幹・歪んだ幹・ソウルサンド・ブラックストーン・玄武岩・マグマブロック・シュルームライト、エンドストーン・コーラスフラワー・エンドロッド・ドラゴンブレス・エリトラ。ネザーとエンドの大きな市場でも、市場ごとに品揃えが変わるようになりました
- **鉄の道具・防具**：鉄のツルハシ・斧・シャベル・ヘルメット・チェストプレート・レギンス・ブーツ、バケツ、ハサミ。鉄の剣とダイヤの品の間の値段です
- **食料・作物**：生の羊肉・生の兎肉・カボチャ・スイカの薄切り・ビートルート・卵・茶色の卵・青い卵・パンプキンパイ・ハチミツ入りの瓶・サトウキビ・氷塊
- **海の品**：イカスミ・輝くイカスミ・プリズマリンの欠片・オウムガイの殻・海洋の心・トライデント
- **矢とモブの素材など**：矢・羽根・火打石・クモの目・ウサギの皮・ハニカム・ファントムの皮膜・アルマジロのウロコ・ブリーズロッド・粘土玉・砂利・不死のトーテム
- どの品も、素材を買ってクラフトして売っても儲からない値段にしています（名札は紙と金属の塊から安く作れるので、商品にしていません）
- **地域の特産**：平原（羊肉・カボチャ・ハチミツなど）、砂漠（サトウキビ・兎肉・茶色の卵）、サバンナ（アルマジロのウロコ・茶色の卵）、雪原（氷塊・兎肉・青い卵）、タイガ（カボチャ・パンプキンパイ・青い卵）、ジャングル（スイカ・羽根・茶色の卵）、沼地（粘土玉・クモの目）、プレイヤーが作った市場（砂利・火打石・バケツ・ハサミ）
- **海辺の市場**：浜辺や海にプレイヤーが作った市場は「海辺の市場」になり、生鱈・イカスミ・プリズマリンの欠片が安く、オウムガイの殻・海洋の心・トライデントも並びます（村がある場所では村の品揃えが優先されます）

#### 進捗

進捗の画面に、この Mod のタブ「商いの始まり」を追加しました（29個）。初めての取引、大口取引、品不足の品を売る、商会の裏をかく、10の市場で取引する、★3の依頼、評判「名士」、運び屋の利益、村に8種類以上の建物をそろえる、10万c をためる、などがあります。達成すると経験値がもらえます。評判・所持金・建物の進捗は、前から遊んでいるワールドでも、ログインした時や交易画面を開いた時に付きます。

#### JEI・REI との連携

JEI か REI が入っていると、市場で扱う品で R（レシピ）か U（使い道）を押した時に「市場の相場」のページが出るようになりました。半径512ブロック以内の市場を近い順に5つまで、方角と距離・買値・売値・在庫と一緒に表示します（あなたの評判の割引込みの最新の値段）。どちらも入っていなくても、今までどおり動きます。

### 変更

- **本日の掘り出し物**に高い品が出すぎないようにしました。市場の規模に見合う品だけが選ばれ（小さな集落にエリトラやダイヤの防具は並びません。ダイヤの防具はレベル5の市場から）、高い品ほどまれにしか出ません。設定 `market.specialUseGrade`（規模に合わせるか）と `market.specialPriceExponent`（高い品の出にくさ、0 で今までと同じ確率）で変えられます
- 「購入」「売却」タブと「まとめて売る」の商品が、値段（基準価格）の安い順に並ぶようになりました
- 掲示板の市場の一覧の右下に「この市場を登録」（JourneyMap が無い時は「この市場の座標」）を追加し、今いる市場そのものも地図に登録できるようにしました
- 購入・売却の一覧で、品不足の商品にマウスを乗せると、基準価格の倍率が出るようにしました
- 交易画面のタブの幅を、それぞれの文字の長さに合わせるようにしました
- ネザーで倒した敵対モブが、ごくまれに（0.5%）金貨を落とすようになりました
- サバンナの村の鞍が1割安くなりました（革が安いので、鞍をクラフトして売ると儲かっていました）
- **商人の服の色**が8種類（青・赤・緑・紫・茶・青緑・灰・黒）になりました。商人が現れた時にランダムで決まります。前からいる商人も、次に読み込まれた時に色が決まります

### 修正

- マルチプレイで、両替タブの「手数料 ◯%」がサーバーの設定ではなく自分の設定の値で表示されていたのを直しました（実際の手数料は前からサーバーの値です）
