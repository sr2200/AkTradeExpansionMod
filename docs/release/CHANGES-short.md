## 未リリース

**追加**
- 村の建物「鋳造所」：両替タブで銅ブロック・鉄ブロックをいつもより多くのコインに鋳造できる
- 道標を並べて2つの市場を「交易路」でつなぐと、遠くても相場が連動する
- 襲撃者の旗持ちを倒すと、高い確率で金貨を落とす
- 品不足の品を16個売って満たすと、発展度のおまけが入り、3回ごとに村人がやって来る
- 村の「元気」：品不足を満たすと上がり、放っておくと下がる（低いと発展度が少し減る）
- 村の建物を8種類追加（駅舎・目利きの店・問屋・商人組合の会館・礼拝堂・村役場・職人の工房・学舎）。交易路・掘り出し物・品不足・番頭・評判・資材・村人の交易・先の見込みにそれぞれ効く

**変更**
- Mod のレシピが、材料などを手に入れるとレシピ本に解禁されるようになった
- 管理者の品揃えの選び直し（market reroll）が、するたびに違う品揃えになる
- 交易画面を開いたままウィンドウを小さくすると、画面がその場で縮んで入る
- 開いている交易画面の市場が消されると、画面が閉じて「この市場はなくなりました」と出る
- 運び屋が空荷で出かけた時も、ログに出発の行が出る
- 建設予定地の杭は、置いた時はチャットに何も出ず、右クリックした時に建てられるかどうかが出る

**修正**
- 村の時計塔の避雷針が錆びて色が変わっていた
- 運び屋を雇う画面の説明が小さい画面で切れていた（スクロールで読める）

## 0.2.0（2026-11-14）

**追加**
- 村の発展：みんなで発展度を貯めて、村に14種類の建物（依頼所・倉庫・銀行・港・祭りの広場など）を建てられる。建物ごとに効果があり、市場の規模も上がる
- 雇い人：運び屋（ほかの村へ運んで売り、帰り荷も仕入れてくる）と番頭（預けた品を少しずつ売る）に、留守の間も商売を任せられる
- 輸送依頼：荷箱をほかの村へ届けて報酬をもらう依頼
- 村の流行と商会の動き：村ごとの人気・余り気味の品や、商会の買い集め・売りさばきで、地域の相場が動く
- 商品を51種類追加（全部で146種類）：ネザー・エンドの品、鉄の道具・防具、海の品など。海辺の市場も追加
- 進捗のタブ「商いの始まり」（29個）
- JEI・REI で、品の近くの市場の相場が見られる

**変更**
- 本日の掘り出し物が市場の規模に合った品になり、高い品は出にくくなった
- 購入・売却の一覧が安い順に並ぶようになった
- 掲示板で、今いる市場も地図に登録できるようになった
- ネザーの敵対モブがまれに金貨を落とすようになった
- 商人の服の色が8種類になった（現れた時にランダム）
- そのほか、表示の改善と値段の調整

**修正**
- マルチプレイで、両替タブの手数料の表示がサーバーの設定と違うことがあった
