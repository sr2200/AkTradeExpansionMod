## 未リリース

**追加**
- 村の発展：みんなで発展度を貯めて、村に14種類の建物（依頼所・倉庫・銀行・港・祭りの広場など）を建てられる。建物ごとに効果があり、市場の規模も上がる
- 雇い人：運び屋（ほかの村へ運んで売り、帰り荷も仕入れてくる）と番頭（預けた品を少しずつ売る）に、留守の間も商売を任せられる
- 輸送依頼：荷箱をほかの村へ届けて報酬をもらう依頼
- 村の流行と商会の動き：村ごとの人気・余り気味の品や、商会の買い集め・売りさばきで、地域の相場が動く
- 商品を51種類追加（全部で146種類）：ネザー・エンドの品、鉄の道具・防具、海の品など。海辺の市場も追加
- 進捗のタブ「商いの始まり」（29個）
- JEI・REI で、品の近くの市場の相場が見られる

**変更**
- 本日の掘り出し物が市場の規模に合った品になり、高い品は出にくくなった
- 購入・売却の一覧が安い順に並ぶようになった
- 掲示板で、今いる市場も地図に登録できるようになった
- ネザーの敵対モブがまれに金貨を落とすようになった
- そのほか、表示の改善と値段の調整
